I Ching · Book of Changes — cast · structure · transform

Boolean Cube 方 — B₃, the trigram lattice

pick the inner (lower) trigram, then the outer (upper) — the pair opens the hexagram. drag to rotate.
eight trigrams = vertices · twelve edges = single-line moves (Hamming 1) · 8×8 = 64 directed pairs = the hexagrams. the diagonal loops on itself.
read as a machine: a trigram is the 3-bit register · an edge is one input · one edge crossed = one transition. the cube is the wiring diagram; the hexagrams live on the pair of two trigrams (two registers, 6 bits).

Grid 表 — upper × lower, all 64 at once

rows = outer (upper) trigram · columns = inner (lower) · diagonal cells are self-pairs. click any cell → open the hexagram.
read as a machine: each row/column index is a 3-bit state · a cell is a pair (outer, inner) · the diagonal is the no-op / self-loop (no change).

King Wen Walk 序 — the sequence as walked

the order read left-to-right, top-to-bottom: № 1 乾 → № 64 未濟.

Radial 轮 — all 64 as one wheel

the wheel holds all 64 — hover a spoke to read it, click to open it.
outward bar = judgment 卦辭 character count inward marks = the six lines, bottom → top (yang one mark, yin two) gold = the hexagram you hold
one turn of the wheel walks the sequence — № 1 乾 at the top, clockwise to № 64 未濟. hover to read a spoke, click to open it.
read as a machine: the wheel and the Walk strip are the same object in two projections; Walk is the linear, keyboard-readable one. the second ordering (binary) sorts the same 64 by their six-bit address instead — the wheel is the only view where the two orderings can be compared side by side.
