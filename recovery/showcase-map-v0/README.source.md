## Geometry contract

### Inner ring — HEADS

Exactly the current public showcase artifacts.

Shape encodes only the declared operation:

- square = CAPTURE
- circle = PLAY
- diamond = REPRESENT
- open arc = PLAN
- triangle = PROVE

Angular grouping is operation grouping, not importance.

### Middle ring — FEDERATION

Six province arcs sized by record count.

Each of the 117 stable IDs is one tick inside its province arc. Tick proximity inside an arc does **not** claim semantic similarity. Search and selection reveal title/purpose/state.

### Outer ring — DELTA

Curated meaningful public events only:

`RECOVER | RELEASE | FIX | VERIFY | INTEROP | SURFACE | CONTRACT`

Clockwise order is time. Selecting a delta exposes commit/source and links it back to a public head where one exists.

## Semantic zoom

Resolution changes; object identity does not:

`ALL → HEADS | FEDERATION | CHANGES → OBJECT → SOURCE/RECEIPT`

No alternate IDs are minted by the map.

## Visual channel law

- black = stable topology/address
- vermilion = change, commit, RETURN
- blue = selected provenance/relation
- opacity = de-emphasis/filter only

No atmospheric/decorative mark carries state.

## Change ledger

`showcase-changes.json` is deliberately curated. It must not become a raw Git log.

Event fields: `id`, `at`, `surface`, `kind`, `sha`, `summary`.

Future automation may derive candidates from Git, but admission to this public ring should remain semantic: a change belongs only if it changes capability, release status, runtime behavior, provenance, or verification state.
