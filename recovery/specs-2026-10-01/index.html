What this is

A corpus sweep of 60,510 machine turns found 325 version-bearing artefact names. 62 of them had no standalone file anywhere on disk. Four are recovered here, verbatim.

The test applied. A name is only listed as a loss if all three hold: the name existed in the corpus · no file backed it (exact-string search across void-anchor, Projects, handover, sovereign-node) · and something references it — otherwise it is an idea that was never a document. Names whose repeats are merely byte-identical chat re-exports are marked as such, not counted as independent later use.
