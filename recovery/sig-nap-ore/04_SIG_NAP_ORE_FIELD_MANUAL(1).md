# SIG NAP ORE — FIELD MANUAL

## Domain
Sig Nap Ore is the nap-show constellation. It may resonate with Singapore and Prison Age, but it is not derived from the glyph system and is not Sine Ore.

## Operating distinction
| Captured pause | Generative pause |
|---|---|
| numbing | sensing |
| avoidance | incubation |
| disappearance | lowered signal |
| indefinite suspension | bounded interval |
| return unchanged | return with one changed rule |

## Protocol
1. Declare a bounded interval.
2. Drop compulsory updates and self-explanations.
3. Notice what remains active without an audience.
4. Extract one ore: image, tension, rule, desire or unfinished move.
5. Refine minimally into a sentence, sketch, object or test.
6. Change one rule of re-entry.
7. Record the delta.

## Anti-avoidance gate
A pause becomes avoidance when the same decision remains pending, no evidence was generated, and the return boundary keeps moving.

Response: reduce the task until one reversible contact is possible.

## Proof
Success produces lower performative noise, one recovered capacity, one changed return rule and one artifact independent of lore.
