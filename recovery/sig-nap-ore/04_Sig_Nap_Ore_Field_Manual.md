# SIG NAP ORE FIELD MANUAL
## Strategic suspension for latent capacity

**Correction preserved:** Sig Nap Ore belongs to the nap-of-China / rest-game cluster. It is not the glyph compiler. Its later integration with the wider system occurs through function, not retroactive renaming.

---

## 1. Use condition

Enter this protocol when:

- continued output is reducing discernment;
- every response is being captured as more evidence for the same model;
- the next move is reactive but not authored;
- exhaustion is being mistaken for truth;
- a possibility needs time before social legibility.

Do not use it to conceal urgent obligations, abandon dependents or convert avoidance into mystique.

---

## 2. The four states

| State | Signal level | Function | Failure mode |
|---|---:|---|---|
| WAKE | high | contact, action, coordination | overexposure |
| HALF-SLEEP | variable | recombination, weak-signal sensing | drift without capture |
| SLEEP | low | repair, consolidation | indefinite retreat |
| RETURN | selective | re-entry with changed rule | resuming unchanged loop |

---

## 3. 27-minute field cycle

### 0–3 min — CLOSE
- name the active demand;
- write what you are refusing to solve during the interval;
- set the return time.

### 3–9 min — DROP SIGNAL
- remove screens, speech, task switching and performance cues;
- lower posture and breathing effort;
- do not seek insight.

### 9–18 min — DRIFT
Allow fragments. Record only after the interval unless a single phrase repeats three times.

### 18–23 min — EXTRACT ORE
Capture no more than three items:
1. unnoticed pressure;
2. latent possibility;
3. smallest changed rule.

### 23–27 min — RETURN
Choose one:
- act now;
- schedule one bounded test;
- explicitly discard the fragment;
- repeat once only if restoration, not avoidance, is occurring.

---

## 4. Ore quality test

A fragment is ore when it:

- was unavailable under continuous performance;
- changes a decision, not only a mood;
- can be formed into a tool, question, protocol or test;
- survives a next-day reread;
- does not require grandiosity to feel meaningful.

## 5. Anti-capture checks

- Did rest become another identity performance?
- Did the protocol produce a changed rule?
- Was the return time honored?
- Did anyone else bear an unchosen cost?
- Is the fragment being protected from testing because it feels sacred?

## Distillation

> Rest is action before the system can recognize its shape; return is proof that the rest carried capacity.
