# BY // GRID PATH COMPILER v3 — CORPUS BRIDGE

## Core decision

The path engine is broader than Jueju and broader than any one grid poem.

Shared portable substrate:

```text
CELL    = stable source identity
EDGE    = observed geometry + typed BY relation
PATH    = ordered program
ADDRESS = exact/loss-aware compression
VIEW    = unequal projection
RETURN  = replayable receipt
```

Corpus-specific meaning is supplied by adapters, not forced into the grid.

## Two live poetry adapters

### JUEJU / VERSE

The 4 × 7 fixture treats:

- four rows and seven characters per row as meaningful source structure;
- selected traversals as possible readings over the verse matrix;
- row/column/diagonal/custom paths as constructions, not automatically canonical lines;
- historical rhyme / 平仄 as OPEN unless a sourced historical validator is attached.

The path engine therefore supports Jueju without claiming that geometry is regulated-verse prosody.

### CELL POETRY / MEANTOME

The 16 × 16 MEANTOME fixture treats the work as a labelled spatial field with authored / declared routes and an edge contract.

The current adapter checks:

- exact 16 × 16 source shape;
- the CODE / SEAL / TIME / TOME source row;
- route status remains distinct from reachability.

A string found by search or drawing is not automatically authored poetry. It can be explicitly promoted and assigned a status.

## Explicit route → motif promotion

v3 implements a conservative promotion gate.

A route can be named and kept as:

- MANUAL MOTIF
- AUTHORED / DECLARED
- CONFIRMED
- LATENT / DISCOVERED
- REJECTED / CONTROL

Promotion records source pack, source fingerprint, path identity, address, reading, cell sequence, strand breaks and typed edges.

This is an authorship/editorial action. It does not turn route reachability into dictionary truth or literary value.

## MAP semantic zoom

The macro atlas now has three densities:

- FLOW — only the construction chain.
- SCOPE — default first-use overview: current corpus + construction chain + frontier status.
- FULL — detailed live capabilities, linked instruments and next frontiers.

The same state underlies all three.

A START HERE sweep briefly highlights:

```text
SOURCE → DRAW → BY → PATH → VIEWS → RETURN
```

without adding a blocking onboarding screen.

## Linked instruments

The MAP links to companion artifacts rather than merging them into the compiler:

- Projection Contract Harness
- ANTHROPY Pathweaver / Jueju composer
- Foundry Federation
- House / POLY through Federation

The standalone Cabinet now exposes its embedded app payloads to the active compiler, so these linked-thread cards can open companion instruments even when only the single Cabinet file is present.

## Important non-convergences

This build does not claim:

- Jueju == cell poetry;
- geometry == semantics;
- a found string == authored poem;
- a path == a lexical item;
- Chinese poetic constraints == English grid-cell constraints;
- House/POLY rooms == poem cells.

The common machinery is addressability + typed traversal + provenance + projection + return.
