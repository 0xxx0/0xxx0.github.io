REFINEMENT HARNESS

Build → test → feel → cut → keep

This panel is intentionally part of the single file. Automated checks catch structural breakage; the manual gates catch the things code cannot decide for us.

Quality gates · use these before adding features
1 · FUNCTION
Every visible control changes a visible state or produces an artifact.
2 · LEGIBILITY
One focal object per viewport; secondary detail is a sheet, not another dashboard.
3 · REVERSIBILITY
Experimental operations can be undone; reference material cannot be silently overwritten.
4 · PROVENANCE
Observed / inferred / hypothetical / generated are not visually laundered into one status.
5 · MOBILE
No essential control depends on hover or clipped side rails. Touch targets survive a phone viewport.
6 · DELIGHT
Motion, sound and visual drama must reveal state, causality or rhythm—not decorate inactivity.
Extension boundary
A proposed addition must enter as one of: operation · analyzer · renderer · exporter · fixture · test. Otherwise it stays in notes until the architecture earns another category.
