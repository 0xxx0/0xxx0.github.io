## Print law

Print `field-route-tile-v0.1.svg` at **100% / Actual Size / no fit-to-page**.

Before cutting, measure the calibration line. Continue only if it reads **100 mm ± 1 mm**.

Written dimensions remain authoritative.

## One-specimen proof

1. Print one sheet.
2. Verify the 100 mm calibration line.
3. Cut one 120 × 45 mm tile.
4. Place it temporarily at one real work surface. No permanent mounting required.
5. Handwrite one actual current `φ FOCUS`.
6. Capture one photo with a ruler or scale reference.
7. RETURN: record measured tile size, placement/context, whether the text is readable at ordinary working distance, and any ambiguity in tracing the tile back to its source.
