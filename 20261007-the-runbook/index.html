02slack — setup tips, check these first

  • Retention first. Set workspace retention deliberately, then override per conversation where a matter needs it. The per-conversation setting is the one that shows up in disputes.
  • Legal holds preserve, they do not reveal. A hold saves data from deletion; it does not give access to the preserved content. And holds are not supported on Slack Connect channels — there, messages follow the retention policy of the sender's org.
  • Audit logs: token discipline. The Audit Logs API only accepts a user token (xoxp…) of an Enterprise org owner — org-admin tokens are not supported. Use a dedicated persistent admin account; if the installing owner is deactivated or drops below Org Owner, the token is revoked.
  • Find the export path before you need it. Discovery / eDiscovery exports: know who runs them and how long they take, before the deadline.
  • AI and ML are auditable settings. The org-level ML opt-out (pref.ml_opt_out) and AI features are governance decisions, not defaults — decide them on purpose.
  • Data residency + Enterprise Key Management where the org requires them; and for Slack Connect, agree guest-vs-channel rules with the other org explicitly.

03slack — scripts, copy-paste

see every auditable action · no auth needed
curl -sS https://api.slack.com/audit/v1/actions
curl -sS https://api.slack.com/audit/v1/schemas
Do this once: the full list of what Slack records, so you know what is answerable.
who logged in, since when
curl -sS -H "Authorization: Bearer $SLACK_OWNER_TOKEN"   'https://api.slack.com/audit/v1/logs?oldest=1759276800&action=user_login&limit=100'
Token: an Enterprise org-owner user token with the auditlogs:read scope. Filters combine with AND; up to 30 action names, comma-separated.
retention & AI-preference changes — the settings that matter legally
curl -sS -H "Authorization: Bearer $SLACK_OWNER_TOKEN"   'https://api.slack.com/audit/v1/logs?oldest=1759276800&action=pref.private_channel_retention_changed,pref.ml_opt_out&limit=100'
Also useful: file_uploaded (egress), pref.msg_edit_window_mins, pref.max_guest_duration. Newest first; max 9,999 events per request; cursor pagination for more; data goes back to March 2018. Rate limit: Tier 3 = 50 calls/min, org-wide.
legal holds — what to know before you place one
Create / edit / release holds and set custodians (that is what decides what gets preserved). Scopes: admin.legal_holds:read / admin.legal_holds:write, granted at the enterprise level. Install at the top-level Enterprise org, with an Owner-level account created for the purpose. Third-party apps using these scopes must be approved via the Slack Marketplace.
