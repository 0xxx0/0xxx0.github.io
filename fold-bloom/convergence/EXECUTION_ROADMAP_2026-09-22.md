# FOLD//BLOOM — EXECUTION ROADMAP
## 0.13 → 1.0 · SOURCE → MAP → PROFILE → PROJECTION → RETURN

**Date:** 2026-09-22  
**Current head:** LIVE 0.13 / LISTEN 0.6 / GLYPH ATLAS 0.2 / EXPERIENCE SET 0.1 / SET 0.1 / TWO DIAL 0.10.3 / ECOLOGY 0.2  
**Purpose:** convert the now-proven single-source ride into a coherent experience system without multiplying disconnected apps.

---

## 0. Current truth

### Proven enough to build on

- One exact audio source can remain identifiable by hash while gaining unequal facets: origin, metadata, text, collection membership, pins and downstream calibration.
- LISTEN can inspect/analyze/annotate a source and share a source-addressed RIDE PROFILE.
- GLYPH ATLAS can compress a source into a deterministic thumbnail and reopen it into bounded facets of the same source.
- LIVE can turn measured source structure into embodied terrain, preserve authored BLOOM/FOLD/SPLIT/RETURN world-writing, and expose source text without claiming false alignment.
- Rare macro events are a better direction than constant spectacle.
- Solid geometry matters. 0.11 proved that increased intelligence can still regress felt reality if the material model becomes visually incoherent.
- A source profile is preference/calibration, not source truth.
- The user's nervous-system report is a first-class promotion gate.
- SET 0.1 can author exact local source refs, order, experiential weight and explicit CUT / DISSOLVE / CARRY / RESET seams, then round-trip the existing Experience Set boundary without storing source bytes or acquiring analyzer authority.

### Not yet proven

- A multi-source set/journey can feel like one authored experience rather than a playlist wrapper.
- A newcomer can understand the family without learning our ontology.
- The same traversal grammar transfers cleanly from music to another source domain.
- A shared annotation/landmark grammar can become a compelling communication primitive.
- Glyph recognition/inside-navigation becomes useful memory rather than merely beautiful indexing.

# 1. North star

## FOLD//BLOOM should become a **Curated Experience Compiler**

A human supplies:

1. one source or an ordered set of sources;
2. optional metadata / text / transcript / images / pins;
3. a small experience profile;
4. optional authored landmarks / transitions / worlds;
5. optionally a destination human.

The system returns:

- a compact inspectable identity;
- a traversable experience;
- a readable map/path;
- a durable, shareable RETURN.

### Core chain

```
SOURCE
  ↓
MAP
  ↓
PROFILE
  ↓
PROJECTION
  ↓
HUMAN OPERATION
  ↓
RETURN
```

Never collapse these stages into one opaque model.

## FRONT B — NORMIE-FIRST UNIFIED SURFACE · STAGED

**Goal:** make first contact obvious without flattening the depth.

### Public first-minute vocabulary

Only three primary verbs:

- **RIDE** — experience it.
- **SEE** — inspect / map / remember it.
- **SHAPE** — tune / annotate / curate it.

Everything deeper remains available through progressive disclosure.

### First-touch contract

A person who knows none of our terms should be able to:

1. drop a source;
2. immediately see a glyph and a playable preview;
3. choose RIDE / SEE / SHAPE;
4. understand that these are views of the **same object**;
5. return to the source without losing work.

### Recovered source-spine law

The later Design/Fold–Bloom thread clarified a missing continuity mechanism; absorb it here rather than creating another app.

**SOURCE SPINE = exact source/set identity + canonical address + aperture + authored calibration/marks + current projection witness.**

- LISTEN is the source editor/cartographer: inspect, align text, pin, calibrate, place a source into a set.
- LIVE/RIDE consumes the same address and authored state without gaining MAP authority.
- READFIELD/RSVP is a reading projection at the same address, not merely a launcher link.
- ATLAS is memory/inspection of the same source cell.
- A persistent rail/background position witness may survive projection changes, but it is projection state, not source truth.
- Nonlinear text correction, when implemented, must be authored **anchor/warp calibration beside immutable cue evidence**; never rewrite source cue times to make the display look aligned.
- The current global text offset remains a valid one-anchor special case.

This is a mechanism refinement of G2/G4, not a new ontology or fourth active front.

### Surface convergence

Do not merge the engines. Merge the **doorway**.

One source header should persist across projections:

- glyph;
- title / origin;
- current source position;
- current profile;
- landmark count;
- projection switch;
- RETURN/share.

LISTEN, Atlas and LIVE may remain internally unequal.

### Promotion gate

Give the surface to a new human with no explanation. Pass if they can:

- load one source;
- enter RIDE;
- find SEE;
- change one SHAPE parameter;
- return;
- explain in their own words that they were manipulating one source through different views.

## FRONT C — ONE NON-MUSIC ADAPTER · PARKED

**Goal:** prove that FOLD//BLOOM is a source-traversal system, not merely an audio visualizer.

### Recommended order

1. **Podcast / talk**
2. **Document / reading**

### Podcast v0 delta

- episode audio = source;
- transcript = text facet;
- chapters = structure facet;
- silence/speech cadence = temporal features;
- landmarks = quotes/topics/user pins;
- RIDE = embodied rhetorical/time traversal;

### Promotion gate

One real episode should allow:

- audio playback;
- transcript follow;
- chapter navigation;
- quote pin;
- ride terrain;
- return to exact same source position from READ ↔ RIDE.

No semantic “understanding” claims are required.

# 7. Verification standards

Every material increment should answer at least one:

- **RE-ENTRY:** is it easier to resume later?
- **IDENTITY:** did the exact source remain clear?
- **EMBODIMENT:** did the body feel more of the source?
- **LEGIBILITY:** can a person explain cause → effect?
- **CURATION:** can the human intentionally shape the experience?
- **TRANSFER:** did a mechanism work in another projection/domain?
- **RETURN:** can the changed state leave as a durable artifact?

If none improve, the increment is probably feature churn.

---

# 8. Promotion criteria for “1.0”

FOLD//BLOOM earns a 1.0-style claim only when:

1. one source can move RIDE ↔ SEE ↔ SHAPE without identity confusion;
2. one 3–7-source set can be authored and traversed continuously;
3. profile/map/source boundaries are inspectable;
4. at least one non-music adapter reuses the same object model;
5. a newcomer gets meaningful delight in the first minute;
6. a human-authored RETURN can reproduce the important experience state;
7. no source provider is required for the core experience;
8. the system remains useful muted / offline / local-first where the source permits;
9. the user voluntarily reuses it in lived experience.

The final criterion is the strongest one.
