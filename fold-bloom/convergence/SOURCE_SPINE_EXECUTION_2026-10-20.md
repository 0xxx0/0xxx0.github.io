# SOURCE SPINE · one thing, unequal worlds
2026-10-20 · recovered / reduced / executable

## Recovered older intent, not new invention
1. `THREAD_COLLAPSE_2026-09-22.md`: LISTEN should be an editor/calibration/annotation surface, not a launcher. The SOURCE SPINE is exact identity + source address + aperture + authored calibration/marks + projection witness; it is **not** another app, timeline store or host authority.
2. `DESIGN_DOCTRINE_2026-09-22.md`: a source may become a glyph, road, reading or world; source != analysis != projection. One thing, many unequal projections. Rare meaningful terrain events beat nonstop spectacle.
3. `EXPERIENCE_COMPILER_SPEC_0.1.md`: song, podcast, document, images and a dayline are instances of addressed source + authored experience. Keep their analysis semantic; do not force audio metrics onto other domains.
4. September interactive-instrument packets: original phone playback was sometimes silent/short/jarring. A non-immersive source view and real audio gate matter more than adding a second graphics engine. User asked for controllable minimap, replay, time address persistence and real brush/ink response.
5. August/September sleeper/city/replay ambitions: sustaining play involves consequential return/replay and variation, not merely moving the scenery. Preserve as experimental donor; do not absorb the game into music's timeline.

## External transfer shortlist
- **Google Paint With Music / Magenta DDSP**: brush Y→pitch with timbre model. Borrow the immediate gestural consequence; discard the novelty claim that drawing becomes music.
- **wavesurfer.js**: regions, markers, minimap, explicit time/seek. Borrow **a readable temporal transport**; our existing source map/glyph and audio elements already own it, so add a source-address slider/ring rather than a second player.
- **Essentia.js**: mature MIR descriptors. Defer dependency until a real failure demands richer pitch/tempo features; the first problem is reliable source handling and RETURN.
- **Spatial room/axial and RSVP**: the underlying gesture is the same hold-focus→change-aperture→act→return. Only this law transfers, not audio sonification or generic ornament.

## Current bounded move
**LISTEN (held @t, pins) → exact source File → native LIVE (one release) → SOURCE RETURN @same t**.

Implementation:
- `listen/pcm-wav.js`: pure bounded PCM16 WAV parser to preview map when WebAudio stalls; no model, network, or global state.
- `live/track.js`: keep original bytes and SHA-256 and native player immediately; bound non-WAV decode; if analysis is unsupported the media remains SOURCE_ONLY (not a fake mapped ride). Stale workers cannot replace another source. No implicit auto-play on bind.
- `lab/media-portal.js`: source glyph remains the original audio glyph. An *additional* temporal progress ring and explicit accessible scrub slider carry the position; identity glyph does **not** misleadingly encode song time. `RIDE THIS` takes a held source address and exact file, verifies LIVE's hash, restores native course position, and `↩ SOURCE` verifies source hash and returns to the held LISTEN address. The return receipt records native release delta, bounded by same source. No native release imitation.
- `lab/source-spine.js`: tiny pure hold/return witness, not an object database. No new collection, persistent store, custom source protocol or flow-wide event bus.
- `live/app.js`: tiny native source seek method requiring same hash.

**5 Tangents parked**: Magenta/DDSP voices, generative style transfer, J-space musical interpolation, room/physical-mural projection, expanded machine-readable music corpora. Every tangent must prove a unique consequential operation before promotion.

## Falsifier
If exact-hash carry or source-address restoration fails, STOP further animation/model/library work. If a native map cannot be derived, show SOURCE_ONLY; never say it is mapped. If Android audio is silent, measure/fix native media path first. If a transformation cannot preserve identity, address and human-authored marks, it belongs in LAB as an experiment rather than as the canonical instrument.
