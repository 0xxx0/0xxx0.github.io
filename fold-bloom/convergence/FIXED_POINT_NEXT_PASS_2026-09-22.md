## Recovered fixed point

The durable mechanism is not any one screen:

**SOURCE → IDENTITY → MULTISCALE STRUCTURE → ADDRESS → GLYPH → PROJECTION → ACTION → RETURN**

Current strongest projections:
- **LISTEN** = addressed source transducer / cartographer.
- **GLYPH ATLAS** = persistent recognition + relation surface.
- **LIVE** = embodied traversal / consequence proof.
- **SET** = compose multiple addressed sources + explicit seams.
- **JOURNEY** = execute/traverse a composed set.

SET/JOURNEY are currently better understood as operators than as equal public destinations.

## Next experiment A — first-class document → Atlas cell

**Do not create a new Document Atlas app.**

Current exact finding: Atlas accepts .txt/.md in the picker, but they are only parsed as sidecars attached to decodable audio. A text document alone currently cannot materialize an Atlas cell.

Smallest meaningful delta:

```
SourceAdapter<Document>
  identity   = SHA-256 exact bytes
  structure  = document → headings/sections → paragraphs
  address    = stable hierarchical ranges
  glyph      = deterministic thumbnail descriptor
  inspect    = READFIELD / source view
  return     = source id + selected address/path + provenance
```

First version should support only UTF-8 `.txt` and `.md`.
No embeddings, LLM summaries, semantic clustering, PDF parsing, or new app.

Success criterion:
1. load one standalone markdown file;
2. it becomes one normal Atlas cell;
3. focus reveals identity + structural facets;
4. entering it can hand off to READFIELD;
5. exported Atlas/RETURN contains no invented source content.

This is the clean test of whether the mechanism escapes music.

## Next experiment B — physical glyph path

Before adding another digital surface:

- choose **8–12 existing Atlas cells**;
- print or draw each glyph on a small card / label / magnet;
- glyph dominant on front;
- tiny human-readable name + QR/address/provenance on reverse or edge;
- arrange them into a deliberate physical path;
- walk / touch / reorder / recall from the path.

Test:
- Can cells be recognized without labels?
- Which visual channels remain distinguishable at ~20–35 mm?
- Does spatial order become memorable?
- Does physical manipulation make SET/JOURNEY immediately more legible?

Do not encode more data into glyphs to rescue poor discrimination.
**Hash/address = identity. Glyph = recognition. Atlas = relation. Lens/focus = inspection.**
