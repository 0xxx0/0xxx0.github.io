# 0. Working thesis

The most transferable Fold/Bloom mechanism is not “music visualization.”

It is:

> **one addressed object may be encountered through several unequal perceptual / analytic / performative projections while identity, position, authorship and RETURN remain recoverable.**

A useful formal pattern is **DUAL-LANE ADDRESSING**.

It is deliberately not a product name.

```
LANE A — CANONICAL
exact object
canonical address
source evidence
provenance

          ⇅ explicit mapping / calibration

LANE B — PROJECTION
performance
terrain
reader
sonification
hypothesis
summary
song
simulation
other representation
```

A second projection may be added, but every lane must answer:

- **what exact object am I about?**
- **what is my address back into it?**
- **what kind of mapping joins us?**
- **what was measured vs authored?**
- **what uncertainty exists?**
- **how do I RETURN?**

This makes “merge two perspectives” lawful without pretending the perspectives are interchangeable.

# 1. Mapping classes

Every cross-projection connection should declare one of these.

## EXACT

A deterministic address conversion.

Examples:
- audio time → timed transcript cue;
- source hash → same local source;
- document char index → same text span;
- file + line → exact code address.

## DERIVED

Computed from evidence with known algorithm/provenance.

Examples:
- source time → estimated section;
- source sample → energy/flux;
- log event → derived density window.

Derived mappings may be recomputed. They are not authored meaning.

## CALIBRATED

Human-authored correction layered beside evidence.

Examples:
- lyric offset;
- future multi-anchor lyric drift correction;
- sensor zeroing;
- user-selected ride/profile gain.

Calibration must never silently rewrite evidence.

## ESTIMATED

Useful but explicitly uncertain.

Examples:
- untimed lyrics distributed across track duration;
- inferred paragraph↔audio segment without timestamps;
- approximate photo sequence time from incomplete metadata.

Estimated mappings must remain visibly weaker than exact/calibrated mappings.

## UNRESOLVED

No trustworthy mapping exists.

This is a valid result.

Do not create a false bridge merely because two views would look good together.

# 2. Research neighbors and what they actually donate

The project is a composition of established ingredients plus its own authority/RETURN discipline. No novelty claim is needed for the ingredients.

| Research lineage | Useful result | Transfer into FIELD/Fold-Bloom | What it does **not** prove |
|---|---|---|---|
| Weiser & Brown — Calm Technology | information can move between center and periphery of attention | fading SOURCE SPINE, ambient source horizon, peripheral state witnesses | that every interface should be calm; LIVE may deliberately be intense |
| Peripheral interaction | some interaction/status can remain usable outside focal attention | low-attention controls / state signals / ambient status | that hidden automation is acceptable |
| North & Shneiderman — coordinated views | linked overview/detail or multiple views can aid complex exploration | dual-lane projections / linked focus / SEE↔RIDE↔READ | that every view should be synchronized bidirectionally |
| Cockburn/Karlson/Bederson — overview/detail, zoom, focus+context | different context/focus strategies solve different tasks | APERTURE selection should be task-specific | that one universal zoom metaphor is best |
| Zacks et al. — event segmentation | humans segment continuous activity hierarchically; boundaries affect memory | section/phrase/event witnesses; journey seams; “massive drop” as relative event | that machine segmentation equals semantic truth |
| Witek et al. — groove / movement | medium syncopation produced strongest movement/pleasure ratings in their study | embodiment evaluation should include “want to move,” not only timing accuracy | a universal optimal groove profile for all music/listeners |
| Spence — crossmodal correspondences | some sensory mappings are systematically associated | candidate visual/audio mappings can be tested for congruence | arbitrary sound→color/shape mappings are meaningful |
| Sonification research | multidimensional data can be mapped into auditory parameters; mapping choice matters | Hermes/Nexus/data archaeology, temporal monitoring, “ride the data” experiments | that musical/aesthetic sonification preserves analytical fidelity automatically |
| Enge et al. — sonification + visualization review | combined sonic/visual representations are a mature design space with open mapping problems | dual-lane data views, visual+aural analytical lenses | that adding sound improves every task |
| Analytic provenance / sensemaking | interaction history + findings/provenance can support review and collaboration | RETURN, marks, research trails, Hermes/Nexus archaeology | that full interaction logging should be shown in the primary UI |
| Music-emotion research | emotion annotation is subjective and listener/context dependent | emotion/mood should be human/profile state or probabilistic evidence, never source truth | that a classifier can tell the user “what this song feels like” |
| PoeticTTS / prosody research | poetry TTS benefits from explicit prosody control and human-in-loop manipulation | poem ride, recitation lane, TTS/voice projection | that one synthetic performance is canonical reading |
| Adaptive cognitive systems | workload/state can sometimes be estimated and used for adaptation | later suggestions for low-stim / focus / intense profiles | that inferred internal state authorizes silent interface mutation |

# 3. Research anchors

## 3.1 Attention / ambient orientation

**Weiser, M. & Brown, J. S. (1995/1996), Designing Calm Technology.**  
https://calmtech.com/papers/designing-calm-technology

They frame calm technology as information moving between peripheral and central attention.

**Heijboer et al. (2016), Facilitating peripheral interaction.**  
DOI: 10.1007/s00779-015-0893-5

### Fold/Bloom hypothesis

A thin source-position / structure witness may improve **reorientation after interruption** without occupying focal attention.

Test it as an orientation instrument, not decoration:

- reacquire source position after 10–30 s interruption;
- wrong-scale / wrong-source action rate;
- subjective distraction;
- whether the witness is noticed only when needed.

---

## 3.2 Coordinated unequal views

**North & Shneiderman (2000), Snap-together visualization.**  
DOI: 10.1006/ijhc.2000.0418

Their work allows independent visualizations to be coordinated through explicit relationships; their studies reported large task-dependent benefits from overview/detail coordination.

**Cockburn, Karlson & Bederson (2008), A Review of Overview+Detail, Zooming, and Focus+Context Interfaces.**  
ACM Computing Surveys.

### Fold/Bloom hypothesis

RIDE / SEE / READ do not need feature parity. They need **explicit address coordination**.

A useful comparison is:

```
UNLINKED VIEWS
vs
SAME OBJECT + SHARED ADDRESS WITNESS
vs
FULL NAVIGATIONAL SLAVING
```

The middle condition may be strongest because it preserves awareness without stealing authority.

---

## 3.3 Event boundaries / anticipation / consequence

**Zacks et al. (2007), Event perception: a mind-brain perspective.**  
DOI: 10.1037/0033-2909.133.2.273

**Zacks & Swallow (2007), Event Segmentation.**  
DOI: 10.1111/j.1467-8721.2007.00480.x

Event boundaries emerge when ongoing predictions change/fail; event segmentation influences memory.

### Fold/Bloom hypothesis

The ride should expose **hierarchical transition pressure**, not continuously maximize spectacle.

Potential generic event descriptors:

- BUILD;
- BOUNDARY;
- CONTRAST;
- RELEASE;
- RECURRENCE;
- NOVELTY.

These can exist across audio, prose, logs and daylines, but domain adapters define their evidence.

---

## 3.4 Embodiment / groove

**Witek et al. (2014), Syncopation, Body-Movement and Pleasure in Groove Music.**  
DOI: 10.1371/journal.pone.0094446

Medium syncopation in their stimuli produced the strongest ratings of wanting to move and pleasure.

### Implication

Do not evaluate LIVE only with:

- frame rate;
- event precision;
- audio-feature accuracy.

Also ask:

- did I anticipate something?
- did my body respond?
- did the source feel more inhabitable?
- did movement help or interfere?
- did a large event feel earned?

The user's “nervous system” report is therefore a legitimate **human-response measure**, not a substitute for technical evidence.

---

## 3.5 Crossmodal mapping

**Spence (2011), Crossmodal correspondences: a tutorial review.**  
DOI: 10.3758/s13414-010-0073-7

### Implication

Visual/audio mappings should be treated as testable design hypotheses.

For example:

- higher spectral brightness ↔ sharper / lighter / higher visual structure;
- low sustained energy ↔ visual mass / weight;
- increased temporal density ↔ increased texture frequency.

But:

> correspondence is not semantics.

Do not turn “sounds bright” into “source means joy.”

---

## 3.6 Sonification and “ride the data”

**Enge et al. (2024), Open Your Ears and Take a Look: integration of sonification and visualization.**  
DOI: 10.1111/cgf.15114

**A Systematic Review of Mapping Strategies for the Sonification of Physical Quantities** (2013).

**Vogt et al. / Organised Sound (2014), Interactive Sonification for Data Exploration.**  
DOI: 10.1017/S1355771813000393

### Implication

The Fold/Bloom control/mapping system can be used “backwards”:

```
DATA SOURCE
→ normalized evidence channels
→ visual projection
+ auditory projection
→ linked address / scrub / aperture
→ human marks
→ RETURN
```

This is potentially valuable for:

- Hermes/Nexus event streams;
- repo histories;
- sensor streams;
- long logs;
- performance traces;
- experiment data.

The purpose need not be “make data into music.”

There are at least three different goals:

1. **monitoring** — anomalies should pop peripherally;
2. **exploration** — scrub and compare patterns;
3. **aesthetic transformation** — intentionally make a musical/artistic projection.

Those goals require different mappings and evaluation.

---

## 3.7 Emotion / mood — useful but dangerous

**Zentner, Grandjean & Scherer (2008), Emotions evoked by the sound of music.**  
DOI: 10.1037/1528-3542.8.4.494

**Yang & Chen (2012), Machine Recognition of Music Emotion: A Review.**  
DOI: 10.1145/2168752.2168754

Modern reviews continue to emphasize listener/context dependence and the distinction between perceived emotion and felt emotion.

### Rule

Never store:

```
source.mood = SAD
```

as if it were objective evidence.

Prefer:

```
analysis.affect_estimate = { model, dimensions, uncertainty }
human.felt_state = { user-authored, time/address }
human.perceived_expression = { user-authored, time/address }
profile.desired_state = { selected intention }
```

These are different objects.

### Literal use

A person may deliberately author:

- “make this ride calmer”;
- “I experienced this region as grief”;
- “show me sections I marked as charged”;
- “compare my felt-state path with acoustic-energy path.”

That is useful precisely because authorship is explicit.

---

## 3.8 Poetry / TTS / performed text

**Koch et al. (2022), PoeticTTS — Controllable Poetry Reading for Literary Studies.**  
arXiv:2207.05549

**After Scansion: Visualizing, Deforming, and Listening to Poetic Prosody** documents literary work using pitch/timing visualization and manipulated/resynthesized recitation.

### Poem Ride

A poem offers a strong non-music proof because it naturally has two unequal lanes:

```
TEXT LANE
exact characters / lines / stanza / syntax / meter candidates

PERFORMANCE LANE
human recording or TTS
time / pauses / pitch / emphasis / breath groups
```

Join them only through an explicit alignment.

Then allow:

- READFIELD canonical text focus;
- optional TTS/human recitation;
- pitch/pause/prosody as evidence;
- visual trajectory as projection;
- reader-authored marks;
- alternate performances as sibling projections.

### Crucial law

The performance does not become “the poem.”

The poem does not fully specify the performance.

That inequality is exactly what makes the dual-lane system interesting.

# 4. Literal off-label use cases

These are **candidate transformations**, not a backlog.

## A. POEM / SPOKEN TEXT RIDE

Input:
- poem text;
- optional human recording;
- optional TTS;
- optional meter/prosody analysis.

Canonical address:
- text source index.

Secondary address:
- audio time.

Candidate projections:
- PAGE / RSVP;
- recitation;
- pitch/pause contour;
- ride/terrain;
- poem glyph.

Human operations:
- mark;
- choose performance;
- calibrate alignment;
- compare performances;
- RETURN a reading path.

First proof:
- one short poem;
- two performances;
- can the reader stay oriented while switching text ↔ sound ↔ ride?

---

## B. TEXT → SONG / SONGIFICATION

This is **authored transformation**, not analysis.

```
SOURCE TEXT
→ selected structure / marks
→ musical constraints
→ human/model composition
→ SONG PROJECTION
→ exact RETURN to text/decisions
```

Possible uses:

- turn a poem into a song while preserving line/phrase addresses;
- make a mnemonic musical projection of a document;
- expose two different musical interpretations of the same text;
- use the song as an alternate reading/performance, not as semantic proof.

Evaluation:

- can a listener return from a musical moment to the source passage?
- which mappings are explicit?
- what was composed vs derived?
- does the transformation aid recall / feeling / communication?

## C. HERMES / NEXUS DATA ARCHAEOLOGY

Object:
- repo history;
- conversation/event corpus;
- task/RETURN stream;
- experiment log;
- ingest/recovery stream.

Canonical address:
- stable event / commit / message / file / receipt id.

Apertures:
- item;
- cluster;
- session;
- day;
- lineage;
- corpus.

Projections:
- ordinary timeline/table;
- AXIAL constraint/support view;
- graph;
- Source-Spine-like progress/region witness;
- sonification;
- summary/READFIELD;
- anomaly lens.

Candidate sonification channels:

- event density;
- branch churn;
- unresolved residue;
- source-age;
- test failure / recovery;
- uncertainty;
- cross-lineage transfer.

### Important

Do not sonify “importance” unless importance itself is human-authored or operationally defined.

Use sound to surface **structure**, not pretend structure is judgment.

A potentially strong mode is:

> browse logs visually while the peripheral audio channel carries density / novelty / unresolvedness.

That connects Calm Technology, sonification and analytic provenance without turning Nexus into a music app.

## D. COMMS / HUMAN PORT

Object:
- exact message/thread/promise bundle.

Address:
- message / clause / ask / commitment.

Projections:
- original thread;
- laconic response;
- spoken/TTS rendering;
- plan/task;
- timeline;
- recipient-specific summary;
- optional experiential vignette.

Possible use:

- “ride” a long emotionally/operationally dense thread;
- hear shifts in turn-taking or unresolved asks;
- preserve one source spine while switching original ↔ summary ↔ action list;
- attach human marks such as PROMISE / DECISION / WAITING / FEELING.

### Rule

Tone/mood inference must never silently rewrite intent.

The agent-router's requested-outcome / facts / constraints / time-horizon / uncertainty extraction remains the operational source.

- CALM / LOW-STIM;
- FOCUS;
- TRANCE / FLOW;
- REVIEW;
- HIGH-CONTRAST / ALERT;


# 5. AXIAL / Lens / Fold-Bloom — complementary operators

Do not merge these into one interface.

## AXIAL

Question:
> Given unequal dimensions/constraints, where is there lawful support?

Strength:
- categorical orientation;
- variable-cardinality dimensions;
- supported/dead possibilities;
- fixed gate + current-position witness;
- never silently chooses.

## Scale Lens

Question:
> How may this object be refracted at another scale/type while identity and RETURN remain stable?

Strength:
- typed projection;
- deep inspection;
- provenance.

## Addressed Continuity / Source Spine

Question:
> What minimal state must survive while I move between those projections?

Strength:
- locatedness;
- re-entry;
- canonical address;
- human marks/calibration;
- projection witness.

## Fold/Bloom

Question:
> What does it feel like to **traverse / perform / inhabit** this addressed source?

Strength:
- temporal embodiment;
- anticipation;
- world projection;
- authored topology/experience.

## READFIELD

Question:
> How do I preserve one source position while reading scale, pace and modality change?

Strength:
- canonical text position;
- semantic aperture;
- RSVP/voice/context.

## HUMAN PORT / agent-router

Question:
> What is the smallest lawful transformation/action on this human/world event?

Strength:
- permission;
- policy;
- requested outcome;
- bounded action;
- RETURN.

### Composition example — Hermes/Nexus archaeology

```
FIELD      locate object
AXIAL      constrain / orient
LENS       inspect alternate representation
SOURCE SPINE keep address
READFIELD  read exact text/evidence
SONIFICATION peripheral temporal witness
HUMAN PORT route a consequential ask/action
RETURN     preserve proof/residue
```

This is much stronger than asking one “universal UI” to do everything.

# 6. Evaluation matrix

Every speculative transfer should beat a simpler control condition.

| Dimension | Question | Candidate measure |
|---|---|---|
| Identity | Do I still know what object I am in? | wrong-object action rate |
| Address | Can I recover my place after a projection switch? | time-to-reacquire; address error |
| Aperture | Can I change scale without losing location? | reorientation time |
| Legibility | Can I explain why a perceptual event happened? | cause→effect explanation |
| Agency | Did the system act beyond my authored permission? | authority violations |
| Embodiment | Did the projection create useful bodily/attentional response? | self-report + task effect |
| Peripheral value | Can the cue inform me without demanding focus? | detection / distraction tradeoff |
| Mapping fidelity | Does the second lane accurately map back? | alignment / inverse-map error |
| Provenance | Can I distinguish measured, estimated, calibrated, authored? | classification errors |
| Memory | Does segmentation/projection improve later recall? | delayed recall / boundary recall |
| Sensemaking | Did the projection help discover/review a pattern? | task time / insight provenance |
| Re-entry | Can future-me resume? | cold-start time |
| RETURN | Can another human/agent reproduce the consequential state? | replay / reconstruction success |

### Evaluation law

A delightful projection is allowed to be worthwhile even if it does not improve analytic task performance.

But we should name the target:

- **instrumental**;
- **experiential**;
- **communicative**;
- **mnemonic**;
- **aesthetic**.

Do not claim the evidence from one target proves another.

# 7. Novelty posture

The ingredients have substantial precedent:

- focus+context;
- calm/peripheral interfaces;
- coordinated views;
- sonification;
- event segmentation;
- analytic provenance;
- adaptive interfaces;
- expressive TTS.

The potentially distinctive contribution is the **composition and use**:

> exact addressed objects moving across analytic, embodied, textual, auditory and authored projections while authority classes remain explicit and RETURN remains first-class.

The strongest novelty evidence will not be a conceptual claim.

It will be a small number of use cases where this composition lets a person do something that previously required repeated context reconstruction or separate disconnected tools.

# 8. Research gaps worth assigning to agents

These are research tasks, not implementation tasks.

## GAP R1 — COORDINATION WITHOUT AUTHORITY LEAK

Question:
What interaction patterns let two heterogeneous views share position/context without unwanted bidirectional control?

Look at:
- coordinated multiple views;
- brushing/linking;
- navigational slaving;
- collaborative awareness;
- peripheral awareness.

Deliver:
- 5–10 design patterns;
- known failure modes;
- mapping to SOURCE SPINE laws.

## GAP R2 — SONIFICATION MAPPING CHOICE

Question:
Which auditory variables are reliably discriminable/useful for temporal data exploration, and which mappings create interference?

Deliver:
- parameter/channel table;
- task-specific recommendations;
- warnings on perceptual interaction;
- simple control condition for each.

## GAP R3 — PROSODY / POETRY / TTS

Question:
How should a poem's text address relate to several performed readings?

Deliver:
- alignment options;
- meter/prosody evidence boundaries;
- one minimal Poem Ride spec;
- evaluation against ordinary text+audio player.

## GAP R4 — AFFECT / STATE WITHOUT FALSE TRUTH

Question:
How should felt state, perceived emotion, desired state and model-estimated affect coexist?

Deliver:
- data model;
- labeling language;
- uncertainty/display rules;
- no silent adaptive-authority leak.

## GAP R5 — ANALYTIC PROVENANCE FOR NEXUS

Question:
Can Addressed Continuity + peripheral sonification improve long-form repo/event archaeology?

Deliver:
- one exact Nexus event source;
- candidate address hierarchy;
- visual lane;
- auditory lane;
- mark/RETURN design;
- falsifiable evaluation.
