# FOLD//BLOOM — DESIGN DOCTRINE
## A SOURCE SHOULD BE ABLE TO BECOME A WORLD WITHOUT CEASING TO BE ITSELF

**Date:** 2026-09-22  
**Status:** doctrine for the active Fold/Bloom family; not a claim that every law is permanently settled.

---

There is a recurring failure mode in software:

a thing enters the machine  
and is immediately dissolved into features, cards, scores, feeds, embeddings, metadata and menus.

The machine becomes more elaborate while the thing becomes harder to feel.

FOLD//BLOOM should do the opposite.

A song should remain the song.  
A photograph should remain the photograph.  
A paragraph should remain the paragraph.  
A day should remain the day.

But each may acquire **doors**.

A source may become a glyph, a map, a road, a reading, a path, a world, a message.

The transformations may be strange.  
The identity must remain recoverable.

That is the project.

---

# LAW 1 — SOURCE SOVEREIGNTY

The exact source is not its analysis.

```
SOURCE ≠ MAP ≠ PROFILE ≠ PROJECTION ≠ RETURN
```

A source hash, canonical document identity, event identity or equivalent witness remains the strongest stable reference available.

Analysis can be wrong.  
Profiles can be personal.  
Worlds can be beautiful.  
The source must still be findable.

---

# LAW 2 — ONE THING, MANY UNEQUAL PROJECTIONS

RIDE, SEE, SHAPE, READ, ATLAS, COMPOSE and RETURN are not required to look alike.

They are required to preserve the relationship to the same addressed object.

Feature parity is not coherence.

**Unequal tools can be more coherent than cloned interfaces.**

---

# LAW 3 — THE MAP MUST BE ABLE TO DRAW THE WORLD

When structure matters, do not build a decorative model beside the analytical model.

The same evidence that says “this event is arriving” should be available to:

- timing;
- terrain;
- visual feedback;
- annotation;
- navigation;
- proof.

This is the homoiconic aspiration:

> the representation used to understand the thing should be capable of becoming part of the interface used to act on the thing.

Not everything must literally be self-similar.

But gratuitous duplication is suspect.

---

# LAW 4 — GEOMETRY IS MATTER; EFFECTS ARE ATMOSPHERE

A road that represents embodied traversal should behave like matter before it behaves like glow.

Near surfaces occlude far surfaces.

A drop changes geometry before fireworks.

A split changes traversability before it changes score.

A world should feel physically coherent enough that spectacle has something to violate.

---

# LAW 5 — RARE LARGE EVENTS BEAT CONSTANT SPECTACLE

A source with no contrast cannot surprise.

Therefore:

- quiet must sometimes remain quiet;
- buildup must sometimes remain unresolved;
- a macro event should be earned by relative evidence;
- a giant event should be rare enough to be remembered.

**Anticipation > telemetry.  
Consequence > decoration.**

---

# LAW 6 — ONE SOURCE EVENT, ONE BODY EVENT

Sliding windows, render frames and asynchronous workers must not multiply one source event into repeated spectacle.

The body experiences an event.

Implementation detail must not stutter it into several false events.

Replay or rewind may intentionally rearm it.

---

# LAW 7 — PROFILE IS PREFERENCE, NOT TRUTH

A human may want:

- more immersion;
- less motion;
- stronger drops;
- denser text;
- different timing;
- a different visual world.

These are lawful.

They belong in **PROFILE**.

They must not silently rewrite source evidence.

```
MAP = what was measured
PROFILE = how I want to encounter it
```

---

# LAW 8 — STYLE IS A WORLD, NOT A FILTER

DEEP, TRANCE, WOOD and VOID should not merely recolor a canvas.

A world can change:

- material;
- palette;
- pattern grammar;
- horizon;
- spacing;
- motion feel;
- local synthesis;
- event expression.

But world styling cannot claim the source itself changed.

---

# LAW 9 — MULTISENSORY DENSITY REQUIRES A COMMON CAUSE

Several channels may fire together when they say the same thing.

A macro drop may lawfully affect:

- terrain;
- camera;
- horizon;
- haptic;
- text aperture;
- local synthesis.

because they are witnessing one addressed event.

Independent novelty across channels is not immersion.

It is interference.

---

# LAW 10 — INSPECTABILITY IS PART OF THE MAGIC

The ideal reaction is not only:

> “wow.”

It is also:

> “oh — that is why it did that.”

A glyph should open inward.

A source should reveal its facets.

A profile should show what it changes.

A landmark should return to its address.

A spectacular system that cannot be inspected becomes disposable magic.

A beautiful system whose workings can be entered becomes an instrument.

---

# LAW 11 — CLOSED VOCABULARIES BEFORE FEATURE SOUP

Low-level signals may be numerous.

Human-facing experiential languages should be few.

Prefer bounded sets such as:

- RHYTHM;
- ENERGY;
- SPACE;
- TEXTURE;
- VOICE/TEXT;
- MEMORY.

A vocabulary earns survival when it:

1. can be explained;
2. maps back to evidence;
3. changes experience usefully;
4. transfers across more than one source type without lying.

---

# LAW 12 — THE FIRST MINUTE BELONGS TO THE HUMAN

The deep system may be complex.

The first touch should not be.

A newcomer should encounter:

- **RIDE**
- **SEE**
- **SHAPE**

They can discover the ontology later.

The system should demonstrate itself using its real mechanism, not a fake tutorial animation.

```
REAL MECHANISM
→ SILENT PREVIEW
→ HUMAN TOUCH
→ TAKEOVER
```

---

# LAW 13 — SETS ARE AUTHORED JOURNEYS, NOT JUST PLAYLISTS

A sequence of sources may become a larger source-like object.

A set has:

- order;
- boundaries;
- transition laws;
- acts;
- carried state;
- authored intention;
- an ending.

The sources do not merge into one identity.

The set becomes a higher-order address that preserves its children.

---

# LAW 14 — COMPOSITION SHOULD FEEL LIKE MOVING REAL THINGS

The future set editor should prefer blocks/cells over forms.

A source is a piece.

A transition is a seam.

An act is a region.

A landmark is a mark on the thing.

The user should be able to compose quickly and spatially — closer to arranging Tetris-like pieces than filling a database form — while every piece remains inspectable and recoverable.

---

# LAW 15 — GAME MECHANICS MUST PAY RENT

A streak, score, combo or target is not valuable because games use them.

It survives only if it creates:

- legibility;
- tension;
- meaningful choice;
- replay value;
- learning.

Do not export a score metaphor into communications, reading or memory merely because it exists in LIVE.

Transfer mechanisms, not skins.

---

# LAW 16 — COMMUNICATION IS A FIRST-CLASS DESTINATION

A transformed source may become something another human can enter.

Not merely:

> “here is a file.”

But:

> “here is the path I want you to take through this.”

A communication RETURN may contain:

- source identity;
- path;
- selected landmarks;
- text;
- glyph;
- bounded motion;
- authored world/profile;
- an invitation to continue.

The destination human must remain able to inspect the source and the transformation.

---

# LAW 17 — LOCAL-FIRST IS NOT A LIMITATION

The strongest current Fold/Bloom path works from owned/local media.

That is an architectural advantage:

- exact bytes;
- no provider dependency;
- durable identity;
- offline use;
- fewer policy surprises;
- long-term recoverability.

Remote providers are adapters.

They should never become the ontology.

---

# LAW 18 — BORROWED CLOCK ≠ BORROWED AUTHORSHIP

A song may lend:

- time;
- pulse;
- sections;
- energy;
- events.

It does not get to choose:

- BLOOM;
- FOLD;
- SPLIT;
- RETURN;
- a human annotation;
- a communicative claim.

Evidence can constrain the world.

The human owns authored meaning.

---

# LAW 19 — LINEAR SOURCE / CYCLIC CONTROL ARE UNEQUAL

The source may move forward.

The instrument may cycle.

A ring does not need to be “the timeline.”

A circle can represent:

- state;
- operation;
- mode;
- aperture;
- recurrence.

while a linear source retains canonical position.

This asymmetry is productive.

---

# LAW 20 — THE FAMILY MUST GENERALIZE WITHOUT FLATTENING

Music is the current proving ground.

The same deeper grammar should be able to encounter:

- a podcast;
- a document;
- a photo roll;
- a memory sequence;
- a day;
- a conversation.

But the recipient domain keeps its own laws.

A podcast should not become a song-shaped podcast.

A document should not become a rhythm-game document.

Transfer:

- address;
- hierarchy;
- profile;
- projection;
- landmark;
- traversal;
- RETURN.

Then let the domain speak.

---

# LAW 21 — RETURN IS PART OF THE OPERATION

A transformation is incomplete until it can leave a durable witness.

RETURN should answer:

- what source?
- what address?
- what changed?
- under whose authorship?
- with what profile?
- what evidence?
- what can be replayed?
- what remains uncertain?

This is how the collaboration survives itself.

---

# LAW 22 — DELIGHT IS EVIDENCE, BUT NOT THE ONLY EVIDENCE

A nervous-system response matters.

So do:

- re-entry;
- recognition;
- comprehension;
- control;
- recoverability;
- repeat use;
- successful sharing.

The desired artifact is not merely impressive.

It is an instrument a human voluntarily adopts.

---

# COMPRESSION

If all of the doctrine had to fit on one panel:

> **KEEP THE SOURCE.  
> MAP WHAT IS THERE.  
> LET THE HUMAN CALIBRATE.  
> TURN STRUCTURE INTO A WORLD.  
> MAKE CONSEQUENCE PHYSICAL.  
> KEEP THE MAGIC INSPECTABLE.  
> LET ONE THING HAVE MANY DOORS.  
> RETURN WITH PROOF.**
