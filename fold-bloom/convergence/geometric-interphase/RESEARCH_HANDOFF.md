# Geometric Interphase — bounded convergence experiment

**State:** candidate proof surface; local executable invariants pass. Not a promoted universal geometry, formal theorem, physical fit claim, or human-use result.

## Why this experiment exists

The current INTERPHASE contract already separates `CORRESPOND → PROJECT → OPERATE`, preserves stable identity/focus, requires explicit residue for suppressed channels, and keeps authority in each host. FOLD//BLOOM already separates exact SOURCE, measured MAP, experience projection, authored OPERATION, and RETURN. This experiment tests whether three geometries can be exposed as projections of one addressed object without creating a second source or moving domain authority:

- **LINEAR** — source/time order.
- **RADIAL** — cyclic relation around a current focus.
- **AXIAL** — orientation / constraint axis.
- **FOVEA** — selected facet address; its screen coordinate is incidental.

The `bowtie` is the transfer shape: exact source enters through an address/focus throat, expands into unequal projections, then returns by identity and caller context. It names a tested route, not a new ontology.

## Operational meanings (analogy labels, not historical identity claims)

- **Tzimtzum / contraction:** reduce visible allocation while listing every suppressed facet as residue. Canonical host data remains present. This build does not claim information theoretic compression and makes no theological claim.
- **Hylomorphism / hylo:** unfold the typed facet structure (coalgebra side), then fold it into the projection summary (algebra side). The implementation uses a small executable recursion scheme; it does not claim full categorical generality.
- **Bowtie:** several presentations converge on one stable semantic address and reopen through that same address. This is a bidirectional continuity test, not a geometric identity theorem.
