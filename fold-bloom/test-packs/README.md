## Laws

- hash recognition does not grant source or authorship authority;
- local source bytes stay local;
- pack suggestions are reversible human-editable PROFILE/SHAPE state;
- source cue evidence remains immutable;
- a test pack is evidence infrastructure, not a provider catalog.
