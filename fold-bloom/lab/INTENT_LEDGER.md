Date: 2026-10-03

Scope: `/fold-bloom/lab/`  
Authority: records repeated user intent and transfer targets; runtime/tests remain implementation truth.

This file exists because research and repeated asks have too often survived as conversation but not as executable product constraints.

## Primary law

**ONE ADDRESSED OBJECT → UNEQUAL PROJECTIONS → VISIBLE EDGE OPERATOR → RESIDUE → RETURN**

FIELD LAB is not eight sovereign mini-apps and must not become a universal framework.

No new mode earns existence while an existing projection can lawfully carry the function.

## 1. Recovered recurring asks

These are not new proposals. They recur across the Fold//Bloom / READFIELD / Pathweaver / Interface / J-space work.

### A. Source continuity

The same exact source/address should survive useful transformations rather than forcing re-entry.

Desired proof spine:

`PULSE --CLOCK--> READ --PLACE--> LOCI --TRACE--> INK --RETURN--> SOURCE`

- **PULSE** lends timing only. Clock ≠ authorship.
- **READ** owns exact text cursor/span and regression history through READFIELD.
- **LOCI** places those exact spans without silently retokenizing them into a new source.
- **INK** receives path/trace geometry as a guide; brush marks remain human-authored.
- **RETURN** carries enough source + address + trace evidence to inspect/replay/re-enter.

### B. Ring / path / grid as operational geometry

Repeated desired behavior:

`CELL → EDGE / BY → PATH → ADDRESS → VIEW → RETURN`

The ring should expose relations and reachable operations, not be a decorative mode menu. Ring / annulus / path / grid are projections over addressed state, not competing ontologies.

### C. Edge operators

Important transitions should be visible **on the relation**:

- PULSE → READ = `CLOCK`
- READ → LOCI = `PLACE`
- LOCI → INK = `TRACE`
- any projection → Scale Lens = `REFRACT`
- projection → source/caller = `RETURN`

A user should be able to tell what survives the edge before crossing it.

### D. Receding controls / deeper fewer inputs

Repeated preference:

- touch the material/object first;
- expose 1–3 lawful actions in context;
- move calibration/diagnostics behind an aperture;
- let controls recede after meaningful action;
- preserve stable spatial memory;
- delight should reveal event, relation, successful recall, scale change, or authored consequence.

### E. Research should become mechanism

Research/donor work is valuable only when it becomes one of:

1. a working interaction,
2. a reusable primitive,
3. a measured comparison,
4. a durable design law,
5. a rejected branch with a stated reason.

“Interesting reference” is not a terminal state.

## 4. Small active surface — next three fronts

### FRONT 1 — LISTEN PHONE TRUTH

**Move:** reserve a deterministic phone interaction aperture around LISTEN’s field and controls; test geometry/hit targets, not just DOM/state.

**Done when:**
- no horizontal overflow at 430×900;
- field/overlay have real nonzero viewport geometry;
- SOURCE / PLAY / MARK / USE are visible and hit-testable;
- intake and workflow sheets remain within safe apertures.

### FRONT 2 — RING + SCALE LENS PRIMITIVES

**Move:** one shared polar geometry/control primitive; remove local duplicate; extract Scale Lens presentation geometry from authority-bearing state.

**Done when:**
- LISTEN no longer owns a byte-copy of polar math;
- pure ring geometry has tests;
- Scale Lens spatial projection imports pure geometry while `ScaleLensSpatialAPI/LensState` retain authority;
- no universal ring ontology is introduced.

### FRONT 3 — CONTINUITY DEMO

**Move:** prove one small source through READ → LOCI → INK first, then borrow PULSE clock.

**Demo:** a short 3–5 sentence source.

1. READ at an exact span; mark one difficult phrase.
2. `PLACE` turns exact spans into a small LOCI route.
3. successful route leaves one continuous path residue.
4. `TRACE` opens INK with that route as a faint guide.
5. user draws; RETURN includes source id, exact spans, route, and stroke trace.
6. optional PULSE clock replays the same source pacing without acquiring text authority.

**Stop condition:** do not add another mode, dashboard, source store, game shell, or ontology before this proof works.

## 5. Ring / Lens modularity law

### Shared ring primitive

`/lib/polar-control.js` owns only:

- angle / wrap / circular delta;
- point → slot geometry;
- polar point / slot layouts;
- annulus hit geometry;
- inertial/detent control.

It does **not** own mode names, game verbs, source identity, Lens state, READ cursor, or LAB transitions.

### Scale Lens

Scale Lens remains:

`OBJECT → APERTURE → VIEW / STACK → RETURN`

Projection geometry may be modular. Object identity, address, receipts, caller RETURN and commit semantics remain with the existing Scale Lens state/API.

### FIELD LAB ring

The LAB ring should eventually consume the shared geometry and render edge operators from the continuity graph. On narrow phones it may project to a rail, but the operator/address relationships must remain recoverable rather than collapsing into an unrelated menu.

## 6. Promotion questions

Before calling a LAB change progress:

1. What exact existing object/source became more usable?
2. What old duplicate or friction was deleted?
3. What operation is now possible that was not possible before?
4. What evidence proves it on phone/desktop?
5. What did the research concretely change?
6. What is the exact RETURN path?

If those answers are weak, the change is probably motion rather than convergence.
