# FOLD//BLOOM — DESIGN / SOURCE CONTINUITY CONTRACT

Date: 2026-09-24
Status: CURRENT PRODUCT LAW
Scope: `/fold-bloom/`

FOLD//BLOOM is one instrument family for keeping one thing identifiable while it is read through unequal projections, acted on, and returned with evidence.

## Primary law

SOURCE → ADDRESS → MAP → PROJECTION → OPERATION → TRACE → RETURN

The source does not become its waveform, terrain, glyph, scene, reading layout, mnemonic route, brush trace, or game chart. Those are projections with explicit provenance.

## Layers

1. **SOURCE** — exact audio/text/set identity and bytes where available. Source playback is source playback.
2. **MAP** — measured or derived beat / phrase / section / energy / text / address structure. Uncertainty stays inspectable.
3. **PROJECTION** — terrain, waveform, RSVP surface, loci path, glyph, paper field, data view.
4. **EXPERIENCE** — camera/body gain, anticipation, plunge, trails, scene treatment, local synth. CLEAR / DRIVE / TRANCE / SOFT are preferences, not truth.
5. **OPERATION** — FOLD / BLOOM / SPLIT / RETURN, branch choice, mark, regression, traversal, brush gesture.
6. **RETURN** — enough evidence to inspect, compare, replay or lawfully transform again.

### LIVE A/B/C

- **SOURCE** — original track; no derived terrain; FIELD synth silent.
- **MAP** — source + derived terrain; restrained experience gain; FIELD synth silent.
- **IMMERSION** — source + map + selected experience profile + FIELD synth/world response.

These are three readings of one source, not three products.

A remote source with no locally available map must remain SOURCE-only. LIVE must never project FIELD COURSE terrain as though it were a map of an unrelated song.

## Scene vocabulary

DEEP / TRANCE / WOOD / VOID, and historical MOSS / EMBER / WATER, are presentation vocabulary only. They must not become source metadata, inferred mood truth, or FIELD INDEX categories.

## Continuity compiler

PULSE --CLOCK--> READ --PLACE--> LOCI --TRACE--> INK --RETURN--> SOURCE

Edges are operators, not just links. Borrowed clock never becomes borrowed authorship.

## Interaction law

SUBSTANCE GENERATES FORM.

For each visible control: what object is manipulated, what stable address remains, what relation becomes visible, what operation occurs, what sensory witness proves consequence, what is evidence versus preference, and how does the user RETURN?

Prefer contextual controls, direct manipulation, stable spatial memory, receding chrome and consequence-driven delight.

## Delight law

DELIGHT MUST HAVE A CAUSE.

A drop, flash, sound, haptic, aperture compression, stain, path completion or scale transition should reveal a measured event, authored operation, hidden relation, successful recall, scale transition or recovered state. Decoration that reveals nothing is suspect.

## Source availability law

The public GitHub Pages runtime cannot read private ChatGPT Library files directly.

- Local imports are hashed and retained in the browser-local IndexedDB vault for later picker-free re-entry on that device/browser.
- Cross-device access may use a recoverable provider address when the source already has one.
- CENTER MASS clean-phone playback uses the original provider identity recovered from the uploaded file; the private Library bytes are not copied into this public repository.
- Private-only cross-device synchronization remains unimplemented until an explicitly authorized private store/relay exists.
- No receipt may claim cross-device private media sync merely because a source hash is known.

## Beat Saber law

Beat Saber is a **bounded transform export**, not a finished Beat Saber game.

LISTEN compiles AUDIO MAP events into a Beat Saber v4 mapper/test ZIP containing `Info.dat`, `AudioData.dat`, `ExpertPlusStandard.dat`, minimal `Lightshow.dat`, provenance/README and the exact current source bytes. Measured BEAT/PHRASE/SECTION events remain distinct from authored FOLD/BLOOM operations. OGG/EGG input is labeled `AUDIO_READY_FOR_PLAYTEST` (audio compatibility only; editor/VR playtest remains unproved); MP3/M4A/WAV/etc. is preserved honestly as `NEEDS_OGG_CONVERSION` and must become `song.ogg` before playtest. Human mapper review, cover/publishing polish and in-browser saber-play mode remain separate future transformations.

## Project management

Keep the archive large and the active surface small.

- this file = durable product/design law;
- `control/CURRENT.json` = current collaboration coordination;
- `showcase-manifest.json` = public route identity/lifecycle;
- runtime + tests = implementation truth;
- `returns/` = proof/promotion evidence;
- exact recovered artifacts = provenance/donor truth.

Do not create a second Fold/Bloom roadmap database.

At any time expose at most three real active fronts. Old branches are donors or provenance unless current master reconstructs a bounded missing function.

## Current proof gates

1. **CLEAN PHONE SOURCE** — CENTER MASS opens and audible source playback begins from explicit user action.
2. **RE-ENTRY** — a locally imported track appears under REMEMBERED THIS DEVICE and reopens without a file picker.
3. **LAYER LEGIBILITY** — SOURCE / MAP / IMMERSION visibly differ without source identity changing.
4. **BEAT SABER SURFACE** — LISTEN visibly exports `ExpertPlusStandard.dat`; nobody has to know the hidden event-tape API exists.
5. **LIVED VALUE** — direct use decides whether the ride is useful/delightful; CI cannot substitute for this.
