## PRIMARY LAW

**RECOVER BEFORE INVENTING.**

Then:

`INGEST → IDENTIFY → PRESERVE → CLASSIFY → COMPARE → PROMOTE / QUARANTINE → RETURN`

Evidence classes stay distinct:

- **BYTES** establish the artifact.
- **SPEC** establishes intent / contract.
- **IMAGE** establishes appearance.
- **RECEIPT** establishes observed behavior.

## ACTIVE SURFACE

Migration keeps **≤3 NOW items**.

Everything else belongs to one of:

- **TROPHY** — exact donor/evidence that earned survival
- **EXPEDITION** — concrete source gap with an actionable anchor
- **QUARANTINE** — preserved without promotion
- **ATTIC** — rejected/weak candidate kept as negative knowledge

Large archive. Small active surface.

## QUEUE RULE

Every queue item should state:

`OBJECT → DELTA → RECEIPT → STOP`

Open work only from:

- an exact source anchor,
- a bounded census slice,
- a current missing-function request,
- or a concrete validation failure.

Remove completed work. Collapse duplicate wording. Do not widen a failed source search into general archaeology.

## PROMOTION GATE

Nothing becomes a current/public surface until it clears:

1. **IDENTITY** — what exactly is it?
2. **PROVENANCE** — where did it come from?
3. **MECHANISM** — what useful operation survives?
4. **PAY RENT** — what capability/evidence/constraint does it add?
5. **RETURN** — can the result be verified without erasing the source?

**OLD ≠ IMPORTANT. WEIRD ≠ WORTHLESS. SHINY ≠ TRUE.**

## ANTI-CLUTTER CHECK

After meaningful migration mutation:

- MIGRATION NOW ≤ 3
- no duplicate migration IDs
- no duplicate Field Index routes
- declared internal routes resolve
- completed queue items are removed
- exact duplicates collapse before semantic branching
- donors group into families rather than exploding into cards
- raw child payloads remain parent-owned where appropriate
- quarantine creates **no beautification debt**
- one recovered batch does not become many fake projects

Do not add an address merely because a file renders.

## ARCHAEOLOGIST

One bounded cycle.

Recover **one**:

- exact artifact
- duplicate collapse
- lineage correction
- stale-pointer repair
- donor packet
- precise blocker
- useful rejection receipt

Then stop.

No idle-time archaeology.

## MIGRATION WARDEN

After recovery or repo mutation:

1. collapse stale / duplicate queue entries
2. check NOW ≤ 3
3. group artifacts into existing families
4. sharpen open blockers
5. run route / ID validation
6. update only state that changed
7. RETURN

Organization alone never earns promotion.

## STOP

Stop Migration work when the pass no longer reduces:

`lost lineage · false fanout · duplicate branches · stale pointers · re-entry cost`

or increases:

`exact recoverability · verified state · useful capability · clean handoff`

Then:

**RETURN TO THE LIVING FRONTS.**
