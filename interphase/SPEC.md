# INTERPHASE — one source, movable attention

## Objective and assumptions

Replace the disconfirmed 0.9.0 aggregation with one instrument for entering a source,
locating a meaningful part, changing context, traversing inspectable relations,
making a local edit, and returning exactly. Reading, a spatial walk, JSON inspection
and FIELD navigation must act on the same source and attention coordinate.

Public publication remains authorized. FIELD retains native object/action ownership.
READFIELD retains source analysis and the only playback clock. THE BELL remains an
authored causal domain. Its live code is sleeper/bell-world.js (b4eac95); do not fork
its rules or pretend a generated layout establishes Buddhist meaning.

The user rejected whole-app aggregation, decorative rooms, angle-only signals,
retention/addiction framing, app catalogues as convergence and invented demonstration
stories in place of a real source. Do not rebuild these under different names.

## Formal model

D = exact raw source text + SHA-256 revision + source address.
a = exact UTF-16 character offset + source scope.
p = plain/walk perspective. q = an explicitly lexical search reading.
V = PROJECT(D, a, p, q).

A scope is a native source range, not a screen coordinate. JSON collections,
objects, fields and text words/passages are ranges in the same exact source.
A projection may expose, suppress or reallocate information but cannot establish
source truth, semantic understanding, object identity or additional effect authority.

The implementation must use the existing native source parser and clock. A headless
native aperture skips visual chrome and unused grapheme allocation; it does not
introduce another segmentation algorithm, timer or cursor.

## Required laws

1. Scope and perspective changes preserve the exact source revision and character.
2. Zoom chooses containing/contained native ranges; it cannot widen while narrowing.
   Equal spans with unequal traversal sets remain explicitly named scope choices.
3. Previous/next use the same source units in plain and walk. They clamp at endpoints.
   Playback stops at the end and does not silently restart.
4. Ring angle selects within the held range. Radius changes scope. Keyboard and
   labeled buttons expose the same operations.
5. Every passage, JSON facet and relation resolves to an exact source range.
   Duplicate JSON paths and ill-formed Unicode are rejected for identity/edit claims.
6. GET/PUT laws are concrete: PUT(D, GET(D, range), range) = D; reading the changed
   range after PUT returns the replacement. JSON stays parseable. Edits are local.
7. Projection changes do not enter semantic undo history. Source edits, marks and
   authored links use one bounded local undo mechanism; undo/redo restore exact bytes,
   annotations and attention.
8. A relation names two native ranges, their scopes, exact quotes, a revision and
   a type. It is an interpretation, never proof that one claim supports another.
   Following it restores the destination scope; RETURN restores departure and scope.
9. A RETURN validates source hash, all attention fields, quote/range/revision bounds,
   marks and traversal frames before replacing live state. Rejection preserves state.
   Transport explicitly carries the current revision; session undo history is residue.
10. FIELD ports are resolved from the observed canonical manifest. Supplied packet
    authority, geometry and edited metadata cannot mint native effects.
11. Late source requests cannot replace newer choices. Reader transfer preserves
    source revision, exact cursor and valid matching annotations.
12. At most three primary source ports are visible; remaining ports are explicitly
    retained under SOURCE. Imported text is never executed or inserted as HTML.

A control-sufficiency claim must name its property and horizon. If identical views
hide different lawful moves, the difference remains visible residue; that view does
not own the affected operation.

## One surface

The default is a readable source with surrounding context. Walk perspective recedes
the same DOM passages; forward/back are source order and side doors are cited links.
No generated world or six-office template is substituted for source structure.
An unusual representation must justify itself against plain reading; machine checks
alone do not establish human comprehension or an improvement in lived use.

FIELD itself is one source collection: exact manifest bytes, a routes collection,
and an anchor inside the readable facet of the held route record. Changing records
does not create new documents. The same collection mechanism applies to ordinary
JSON arrays. Titles/body text come from explicit source fields; omitted fields are
counted and the exact raw range remains available.

Search reorders an observer's reading by declared lexical matches. It never changes
source order or creates an inferred semantic relation. Unsupported commands return
a reason instead of operating an invisible FIELD view. The existing address bar
opens source addresses, searches the held source, and aliases actual source moves
such as read, pause, plain, walk, source, return, undo, redo and scope changes.

Native FIELD launch ports remain host-owned. In particular, THE BELL launches its
actual native FPV/PLAN/CAUSE model. This instrument does not claim that its text
reader and that authored simulation share identical effects.

## Implementation

interphase/navigation.mjs consumes native analysis and owns pure range, zoom,
faceting, relation and local-edit laws. interphase/continuum.mjs mounts one shared
surface. field-work.mjs binds that surface directly into FIELD's DOM.
interphase/entry.mjs chooses the source instrument or an explicit legacy fixture.
The legacy workbench is inert until requested. READFIELD and WRIST exchange the
same source/cursor and preserve valid matching source annotations on return.
The pure navigation functions join the existing typed import facade and optional
local package; the UI does not import the entire legacy facade.
