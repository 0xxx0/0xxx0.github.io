ELI5 — what is CS50?

Harvard's free intro-to-computing course. You watch sharp lectures, then fight problem sets that make you think. It starts in C (the hard, old language) so you learn how memory and machines actually work, then moves to Python, SQL and the web. 7M+ people have enrolled; two-thirds had never coded. Which one, by what you actually want

"I want to know what my code is doing underneath."
→ CS50x. The one thing it does better than anything free: memory, algorithms, how computers work. cs50.harvard.edu/x
"I want to be employable and build real things."
→ The Odin Project. Real editor, Git and terminal from day one; free, ~600k learners; the friction is the training. theodinproject.com [reddit consensus: TOP job-ready, CS50 fundamentals]
"I have almost no time and no patience for C."
→ CS50P (Python track, same course family) or freeCodeCamp — complete and free, runs in the browser. freecodecamp.org
"I already code; I want depth + a portfolio."
→ CS50x → CS50W (web) or Full Stack Open (Helsinki, free, university-credit-able). fullstackopen.com
"Will AI do it for me?"
No — and that's the 2026 rule: external AI (ChatGPT/Claude/Copilot) is banned on problem sets; CS50's own duck is allowed. cs50.ai is a "virtual rubber duck": it nudges, it won't hand you the answer. cs50.readthedocs.io/cs50.ai
The trap in this dump: pages 1–2 answer "is CS50 worth it". Pages 24–60 — three quarters of the PDF — stop being about CS50 entirely. They're an AI-Mode thread about building an open-source personal agent harness ("Muse / OpenMuse": browser + files), then enterprise deployment: VPC vs local office machine, Slack integration, and which multi-jurisdiction rules the agent must track (PDPA, Australia's Privacy Act). That's a different question, and it's the one worth asking properly.
What's new in the 2026/27 run (so you don't follow stale guides)

· Carry-over policy: unfinished progress rolls into the 2027 edition.
· 2026 edition ≈ 11 weeks, C in weeks 1–5, then Python/SQL/JS.
· cs50.ai built into cs50.dev; using other AI = academically dishonest.
· Certificate ~$199–219 via edX; audit stays free.
· CS50 family: CS50P (Python), CS50W (Web), CS50AI, CS50T (business).
