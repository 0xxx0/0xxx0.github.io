# CURRENT CONVERGENCE MODEL

INTERPHASE is a shared interaction protocol, not a universal app.

The important separation is:

`CORRESPOND != PROJECT != OPERATE`

### CORRESPOND

Host object → stable semantic facet/role.

### PROJECT

Semantic facet → representation/allocation at a chosen scale.

### OPERATE

Canonical host state → changed canonical host state.

A thing exists once.

Different lawful projections may include:

PAGE / LINE / TABLE / RING / SPIRAL / FLOWER / ROOM / GLYPH / RSVP / FOVEA / physical surfaces.

Changing projection normally does not change the thing.

Single focus and multifocus should survive projection changes.

The host retains domain truth and authority.

Views may not silently grant authority.

RETURN restores caller/context; it is not automatically undo or rollback.

For an operation claimed equivalent through a view, test:

`PROJECT(OP(host)) ~= VIEW_OP(PROJECT(host))`

If this fails, classify why instead of adding hidden synchronization state.
