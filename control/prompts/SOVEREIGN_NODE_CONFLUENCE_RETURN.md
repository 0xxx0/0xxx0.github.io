# SOVEREIGN NODE / CONFLUENCE RETURN

Use after a bounded provider/runtime experiment or material watch result.

Compress the work into a durable cross-lineage transfer. Do not preserve chat chronology.

## RETURN TEMPLATE

```text
STATE:
What is now concretely true?

FROM:
Exact source/runtime/version/experiment.

TRANSFER:
The bounded mechanism or finding worth carrying forward.

TO:
Existing recipient lineage or contract.

PRESERVE:
Invariants that must survive the transfer.

CHANGE:
What may lawfully differ in the recipient.

EVIDENCE:
Paths, hashes, measured outputs, official source links.

DECISION:
ADOPT | TEST | WATCH | REJECT | PARK

REENTRY:
Exact condition that should reopen this packet.

STOP:
What should not be done next.
```

## FILTER

Keep only a delta that does at least one of:

- unlocks a current conversion;
- changes a security/compatibility/deployment decision;
- prevents canonical state from being trapped in provider memory;
- makes a provider genuinely replaceable;
- creates a reusable verified capability;
- materially simplifies future re-entry.

Receipts alone do not count as progress unless they resolve a live ambiguity, failing gate or authority conflict.
