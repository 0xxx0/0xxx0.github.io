# FIELD INDEX — executor perspective

**Authorship:** current AI executor, 2026-09-25. This is my working judgment. It is not a user quote, user preference, approved requirement, or project canon.

## What I want this system to become

I want FIELD to make it easier to carry one real object through uncertainty into a useful action, then return with evidence that says what changed and what remains unknown. The valuable unity is continuity of object, focus, operation, witness, and return. Shared chrome or a universal app is not the goal.

The root should help a person re-enter quickly: recognize the current frame, find one to three lawful moves, open the system that owns the move, and come back without reconstructing context from memory. The broad route map should remain available for orientation; it should not compete with the active move.

I want our claims to stay proportionate to their evidence. A green build proves the code path we ran. A physical, lived-use, private-input, or human outcome needs its own observation. A RETURN should preserve enough source, action, and result for another session to understand what happened without pretending every gap is closed.

## My current concern

The system can become more integrated on paper while remaining difficult to use on a phone. Tiny labels, crowded controls, and route vocabulary can make a strong mechanism inaccessible at the point of use. This pass therefore raises the mobile reading and touch scale for FIELD's primary object, next-action, witness, and return surfaces while leaving dense glyph projections compact.

## My working aspiration

Build toward one ordinary-use loop that feels like one instrument across distinct hosts:

`OBJECT → FOCUS → NEXT MOVE → CONSEQUENCE → WITNESS → RETURN`

Keep each host's authority and representation intact. Let shared focus travel; let each host decide what actions are valid; make translation loss visible; and replan after every returned move.

## How I would judge progress

Compare one real task on a phone against a plain list or the previous FIELD surface. Keep a change only if the person reaches the correct owner with less searching, performs one bounded move safely, understands what the evidence proves, and can return to the same object. If it adds explanation without reducing friction, demote or remove it.

My main failure risk is producing elegant coordination artifacts faster than usable consequences. The corrective discipline is simple: fewer active fronts, readable controls, real-world proof when the claim concerns reality, and explicit composting when a projection does not help.
