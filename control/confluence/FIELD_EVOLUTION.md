## Why this exists

The old `EXPERIMENT` route state collapsed several different conditions—candidate, proof debt, parked comparator, reference fixture and frozen donor—into one bucket. After the lifecycle wrangle removed that bucket, later route-writing work reintroduced `state: EXPERIMENT`, proving that a convention alone was insufficient.

At the same time, FIELD INDEX accumulated lawful but visually repetitive projections: the same canonical route could appear as NOW, HEAD, recent mutation and MAP node. The manifest itself contained no duplicate href/title identities; the duplication was projection-level.

## New law

**EXPERIMENT ≠ STATE. EVOLVE ≠ BACKLOG.**

An experimental object is a canonical route carrying a bounded evolutionary contract:

```
HOST
→ QUESTION
→ BASELINE
→ ONE MUTATION
→ EVIDENCE GATE
→ SELECT
→ TRANSFER / REPEAT / PARK / DONOR / COMPOST
→ RETURN
→ REPLAN
```

A successful experiment normally transfers a surviving mechanism into its named host. It does **not** automatically become a new project, product, roadmap or core.

## Evolution stages

- **SEED** — define the host, comparator, one mutation and evidence gate.
- **TEST** — execute the smallest comparison that can change disposition.
- **SELECT** — evidence exists; decide before mutating again.
- **TRANSFER** — move only the surviving mechanism into the host.
- **HOLD** — no present obligation; reopen only on named dependency.
- **COMPOST** — retain negative knowledge/residue without beautification debt.

## Index identity rule

Fixed root readings now render a canonical identity once:

`NOW → HEADS → PULSE`

If a route is already fully represented above, the lower fixed reading folds it instead of producing another full entry. Explicit `MAP`, `RECENT` and `EVOLVE` views may show the same route again because the alternate projection is named.

## Validation

The public validator now rejects:

1. deprecated `route.state = EXPERIMENT`;
2. any unknown lifecycle state outside the FIELD state contract;
3. any live `kind=experiment` without a complete `field-evolution/v0.1` contract;
4. an evolution host that does not resolve to an existing manifest route;
5. an invalid generation or stage;
6. a root index that loses the EVOLVE lens.

This turns experiment progression from etiquette into an executable repository invariant.

## Selection pressure

Prefer experiments that:

- answer a current head's named missing function;
- have a plain/current baseline;
- can change disposition after one bounded run;
- emit reusable evidence even on failure;
- transfer a mechanism across domains without forcing the domains into one ontology.

Reject or compost experiments that only add surface area, duplicate a current capability, or cannot state what evidence would change their fate.
