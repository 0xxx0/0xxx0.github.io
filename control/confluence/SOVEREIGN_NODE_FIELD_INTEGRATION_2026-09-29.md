# SOVEREIGN NODE → FIELD integration / successor note

## FROM
Repeated ecosystem reconnaissance was useful but risked becoming its own control surface. Live repo truth already had the correct sovereign-node boundary, while MEDIA REFINERY retained one stale bulk-worker name.

## TRANSFER
1. Proof identity is byte/runtime qualified, not version-label qualified.
2. Reconnaissance is delta-only and evidence-only.
3. A tooling change may enter CURRENT only through an existing conversion/security/deployment/authority/rollback decision.
4. Provider/backend transitions are visible; security, invalid-request and authority-denied failures STOP.
5. Model/provider/session memory remains disposable; Git/filesystem/typed receipt/RETURN reconstructs the work.
6. PASS transfers a mechanism into an existing host. PASS does not create a new front.

## TO
- `control/SOVEREIGN_NODE_RUNTIME.json` owns runtime/executor law.
- `control/SOVEREIGN_NODE_WATCH_STATE.json` owns reconnaissance baseline only.
- `control/MEDIA_REFINERY.json` owns the concrete conversion recipient.

## PRESERVE
CURRENT stays conversion-first. FIELD root stays small. No AI dashboard, provider selector, watch queue, universal orchestration shell, or second canonical store is introduced.

## CHANGE
MEDIA REFINERY bulk semantic worker is aligned to `qwen3.5:9b`; 27B remains optional manual adjudication; Hermes remains exception/supervision; Higgsfield remains explicit downstream render authority.

## TEST
Use existing proof surfaces: baseline freeze, Ollama endurance/typed-output fixture, neutral executor bake-off. Test isolated profiles/worktrees before primary-node mutation.

## RETURN
A future scout reports only a material delta with WHAT CHANGED → WHY HERE → DISPOSITION → TEST → PASS/FAIL → ROLLBACK → UNCERTAINTY → PRIMARY SOURCES. If no existing decision changes, silence is the correct output.

## Notes to successors
Do not confuse more intelligence with more authority. Do not confuse continuity with provider memory. Do not confuse a receipt with progress. Do not ask the human to become the test harness for machine-verifiable claims. Exhaust reversible machine proof first; expose only irreducible human/world gates.

The collaboration bottleneck is reduced by making reconstruction cheap: exact source, exact identity, bounded authority, explicit consequence, explicit RETURN. The system should remain useful after any one model, harness, vendor, session, or collaborator disappears.
