# CROSS-SYSTEM PERCEPTUAL / LEARNING EXPEDITION

Status: **research charter / model-agnostic**
Origin: the long Astra-targeted prompt from the tiny-law thread.

The charter is not actually dependent on one model. The model-specific header may be removed. Its durable function is to force a rigorous archaeology → mechanism atlas → controlled comparison → build/test loop across planning, HOUSE, Singapore-law games, JUE/JU, RSVP/Morse/fast encoding, glyph systems, maps, symbolic traditions, and tiny-law instruments.

## Central question

Which recurring perceptual, representational, navigational, mnemonic, learning and transformation mechanisms are genuinely reusable; which are only aesthetic/metaphorical similarities; which systems should remain unequal; and what becomes possible if we systematically vary **content while holding interaction constant**, then vary **interaction while holding content constant**?

## Required discipline

- Recover exact prior artifacts before inventing replacements.
- Build a mechanism atlas, not a project-name list.
- Compare against boring controls: list, table, plain text.
- Separate recognition, recall, production, transfer, engagement, and delayed retention.
- Treat multimodality as a hypothesis, not automatically beneficial.
- Treat spatialization as justified only when location/motion preserves useful structure.
- Separate historical/esoteric formal structure from psychological evidence and metaphysical claims.
- Preserve contradictions and hard non-transfer boundaries.
- Build at least one falsifiable interactive test when the execution environment is authorized.

## Hermes mode

When this charter is pasted into Hermes, prepend:

```
MODE = READ_ONLY_RESEARCH
Authority = recover/search/read/analyse only.
Do not write repositories, move/delete files, send messages, or take external actions.
Where the charter says BUILD / IMPLEMENT, produce a bounded candidate implementation packet instead:
- target
- files/paths proposed
- exact source lineage
- mechanism
- control condition
- tests
- patch outline
- stop condition
Return this packet to ChatGPT/Codex for authorized execution.
```

This preserves the research value without letting the charter's implementation language silently broaden Hermes' authority.

## Useful experiment axes

CONTENT × REPRESENTATION × INTERACTION × TIME × FEEDBACK × NAVIGATION × RULE VISIBILITY × ICONICITY × COMPRESSION × DIFFICULTY.

The valuable outcome is not one master UI. It is a map of where a mechanism wins, loses, transfers, or should remain domain-specific.
