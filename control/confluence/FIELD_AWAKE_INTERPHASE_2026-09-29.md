## RECONSTRUCTED

The six-step WAKE ↔ INTERPHASE correspondence is a current convergence mapping. It is **not** a claim that historical WAKE and INTERPHASE were originally one system.

The mapping survives because the operational rhyme is strong:

- WAKE / SOURCE — receive the object before explanation.
- CUT / FRAME — establish boundary/context.
- HOLD / FOCUS — keep one exact thing in view.
- TURN / OPERATE — expose only lawful moves.
- TRACE / WITNESS — retain observed consequence.
- AGAIN / RETURN — carry evidence back without laundering authority.
