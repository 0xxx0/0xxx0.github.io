## Why this exists

One place for speculative and active flows that are really the same operation under different carriers.

Do not create a new pipeline because the carrier changed.

```
SOURCE
  → FOCUS
  → TRANSFORM
  → COMMIT
  → OBSERVABLE
  → EVIDENCE
  → RETURN / NEXT
```

The implementation may be UI, conversation, an agent run, HAOS event handling, physical actuation, a document transform, or a game mechanic. Carrier is not identity.

## Current primitive

A transduction is recorded as:

| field | job |
|---|---|
| source | what arrives |
| focus | what part/address is selected |
| transform | bounded change |
| commit | where changed state can become durable |
| observable | what can actually be noticed/measured |
| evidence | why the change is believed |
| authority | maximum permitted consequence |
| reversibility | undo/revert/compensation/none |

Composition never raises the weakest member's authority ceiling.

## Lossless artifact folding

The active surface may shrink without deleting history.

A **lossless fold** means that an old surface can stop being a sovereign head when its useful state can round-trip through:

```
SOURCE ID
  → ADDRESS
  → APERTURE
  → PROJECTION
  → OPERATOR + PARAMETERS
  → AUTHORITY / COMMIT
  → RETURN
```

The old file, commit, image, receipt or physical study remains evidence. What disappears is duplicated **operational sovereignty**, not provenance.

The current candidate is one **instrument cell** with unequal projection cells: LINE, RING, SPIRAL, GRID, FOLD, ROOM, RSVP and GLYPH. A host supplies the domain vocabulary; the geometry does not get to invent one.

### Six-sector carrier

A center + six sectors/petals is retained as a useful carrier candidate because the recovered corpus repeatedly used six-way flower/cube/wheel forms and foldable radial material studies. It is deliberately **not** promoted to a six-part ontology.

- center = host-defined invariant / intent / exact focus
- sectors = six host-defined facets, inputs or operators
- rotation/radius/fold only acquire meaning through explicit mappings
- visible operation and commit state must remain legible
- F.L.O.W.E.R. / FU semantics are presets, not compulsory labels
- the exact remembered key-shaped six-panel historical artifact is still UNKNOWN until directly recovered

### Current fold map

- DataDisc/radial + strip + spiral + fan/fold + ROOM + RSVP + glyph → one **projection inventory**.

Do not delete or hide a donor until a round-trip fixture proves source identity, address, aperture, parameters, operator ordering, authority and RETURN survive. If a unique behavior cannot be reconstructed, it has not been folded.

## Active slice: passive refinement

```
use

 → low-risk default
 → use
 → accept / override / backtrack

```

Current branch implementation:

- UI signal metadata stays local.
- Source/payload text is never stored in preference history.
- A FIELD map-mode default requires at least 3 observed choices and ≥0.60 top share.
- HUMAN PORT proposes one likely route.
- Choosing another route is stronger evidence than accepting the candidate.
- No observed preference grants sending, spending, deletion, publication, or physical actuation authority.

## Proposed composition: bounded autonomous work

Not a software factory.

```
CURRENT HEAD
 → find smallest named delta
 → execute
 → verify
 → RETURN
 → re-orient
```

The unit being built is not “software”; it is a verified state transition. Code is only one possible residue.

A recursive run may continue without a human only when a bounded recurrence contract already authorizes the next class of move. Otherwise one consequential delta closes the run.

Sensing and actuation remain separate transductions. More sensing never implies more authority.

Prefer purpose-level events (motion, occupancy, presence, task completion, device transitions) over leaking entity implementation details into FIELD.

## Promotion rule

A speculative composition remains here until it demonstrates one of:

1. repeated reuse across unequal carriers;
2. lower decision/re-entry cost;
3. a clearer evidence/authority boundary;
4. a measurable closed feedback loop.

Then promote the mechanism, not the prose.

## Stop rules

- no new orchestration product for a renamed chain;
- no inference promoted from one observation;
- no recursion without delta or new evidence;
- no pipeline whose output cannot identify its evidence and authority;
- no duplicate world-model beside canonical FIELD/HOUSE state;
- no marketing layer around a transduction.
