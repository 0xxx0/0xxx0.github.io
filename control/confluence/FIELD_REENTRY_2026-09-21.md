# Field re-entry: close loops, do not add a centre

2026-09-21 · bounded coordination audit, not a new architecture or priority authority.

## Reading the whole

The strongest shared pattern is already implemented in pieces: **retain a source → address a part → inspect lawful possibilities → choose an explicit operation → return evidence**. Field/AXIAL organise choice; Lens changes the reading; Port routes material; Painting anchors a finding; City makes source affect consequences. Their differences are useful. There is no demonstrated need to merge them into one app.

The current drag is coordination drift and unfinished evidence, not lack of more concepts. A document says HOLD, a queue says NEXT, an issue still says RECOVER after source exists. That makes completed work look absent and held work look owed.

This pass repairs that specific failure: QUEUE now follows CURRENT; House remains held; City/Painting leave the exact-source gap; actual local ingest replaces the assumption that filesystem access is unavailable. CI now fails if live fronts diverge or that solved source gap silently reopens. Old dated receipts remain historical evidence, not rewritten present truth.

## The path through

1. **Use the present entry point.** CURRENT selects ordinary Human Port/Field use; it does not ask for another dedicated QA ritual. Note an actual confusion or backtrack when it happens.
2. **Turn that friction into one test.** “I could not return to this source” is actionable; “the whole system should be more coherent” needs decomposition. Preserve the original object and plain reading as the control.
3. **Retrieve only the missing mechanism.** The backup is a source quarry. Painting can donate stable region identity; City can donate a verifiable input witness. Neither automatically becomes a product roadmap.
4. **End with a disposition.** RETAIN, REVISE, HOLD or REVERT plus evidence. A completed recovery should close its issue; an unproved usability claim should remain open. No second move inherits authority from the first.

The useful next invention may be subtraction: one less stale instruction, one less repeated paste, one less uncertain identity. Those are measurable gains without deleting the richness of the archive.
