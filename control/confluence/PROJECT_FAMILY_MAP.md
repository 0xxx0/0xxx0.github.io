## Reducer for new work

Before starting anything, place it against this map:

```
1. Which family owns the problem?
2. Which native host owns truth/effect?
3. Which upstream family is actually missing?
4. What proof already exists?
5. What one move would change reality or falsify a live claim?
6. Where does RETURN land?
```

If no answer names a current recipient and one bounded consequence, **do not create a new project**.
