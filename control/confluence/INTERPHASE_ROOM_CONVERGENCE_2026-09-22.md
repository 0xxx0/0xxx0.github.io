## 4 / PROPOSED + IMPLEMENTED — ROOM 0.1

Route: `/foundry/room/`

### Six-face law

```
          +Y  INTENTION / PURPOSE
                 ↑
-X INPUT ←   +Z PRESENT   → +X OUTPUT
                 ↓
          -Y  GROUND / EVIDENCE

          -Z  RETURN / PROVENANCE
```

The oppositions are intentional:

- PRESENT ↔ RETURN;
- INPUT ↔ OUTPUT;
- INTENTION ↔ EVIDENCE.

This keeps the spatial mapping semantically useful and small.

### What actually changes

Rotation changes only the **projection**.

Walking through a wall door changes the **addressed object**, explicitly, and records a local event.

The object is a real route from `/showcase-manifest.json`.

The emitted state follows `0xxx0/interphase/v0.1`.

### Why this is not another dashboard

There is no persistent panel grid.

The dominant surface is the room itself.

A fixed focus gate remains at viewport center; the active wall foveates while peripheral walls remain physically present.

The PLAIN mode is always available as the control condition.
