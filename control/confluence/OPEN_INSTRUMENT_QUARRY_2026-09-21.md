# OPEN INSTRUMENT QUARRY — 2026-09-21

Status: exploratory / non-authoritative  
Purpose: update the collaboration's working model without turning every recurrence into a product plan.

## RECOVERED / OBSERVED

### 1. COMPLEMENTARY COGNITIVE TOOLS is an older governing criterion

Source: Drive `DRaft with Hui` (2021).

The note explicitly contrasts tools that strengthen a person's retained capability with tools that merely replace it. It also groups this with Focus+Context, foveation, log-polar representations, chunking, navigation/memory, multimodal perception and the cost of window/app switching.

Transfer candidate:
- evaluate an instrument by what the human can still perceive/do after the scaffold is removed;
- progressive disclosure should reduce context switching, not merely hide controls;
- a visual projection is useful when it improves retrieval, discrimination, navigation or manipulation.

This predates the current APERTURE / AXIAL / Poem Map branch and should be treated as lineage rather than new theory.

### 2. NAMES AS EXECUTABLE INTERFACES

Source: Drive `HAX Archaeology — lineage, deltas, experiments — 2026-09-13`.

Recovered law:
a useful name should improve retrieval, composition and verification, and may resolve to recognizers/contracts/verifiers rather than just a preferred string.

Interesting transfer:
the labels on an interaction surface could themselves be operational addresses. A verb such as TURN or LOCK is stronger when its admissibility, effect and reversal are inspectable. This is relevant to AXIAL, Poem Map, HUMAN PORT and command/glyph systems without requiring one shared ontology.

### 3. ADMISSIBILITY BEFORE RANKING

Same HAX source.

Recovered split:
- hard constraints decide whether a route is lawful;
- soft preferences rank surviving routes;
- a Pareto frontier is preferable when no single policy is stable.

This appears independently in MARKET+SOLVER, AXIAL lawful support, CENTER work and Poem Map candidate support. It is likely a true reusable mechanism rather than a theme.

### 4. SMALLNESS / SELECTIVITY / THE GRAIN

Source: Drive `2021 GPA EN SCRATCH`.

The scratch repeatedly explores paths, maps, same-name/different-function, game/play/victory, terse overloaded inputs, and the claim that a small selected unit can open onto a much larger world.

Useful reading:
the selected token/cell/object is not merely a filter. It can be a **portal into relevant scale**. That is closer to APERTURE + Poem Map 0.1 than to a dashboard.

The same source defines:
- “A game is: space bounded by victory and defeat, measured by rules”
- “Play is: pursuing a path to victory in a game”
and separately asks for a very fast append-only sequence with an exposed AST and a terse overloaded directional input.

Potential donor:
constraint-game mechanics should make the artifact itself the game-state, not attach points/rewards afterward.

### 5. SINDER / POLY'S OLDER PHYSICAL PRIMITIVES ARE MORE GENERAL THAN FURNITURE

Source: Drive `(3) PRODUCT DESCRIPTION IN DETAIL` (2018).

Recovered decomposition:
- power / sequencing,
- planes / surfaces,
- paths / flows,
- points / joints.

The document also contrasts imperative object definitions with declarative functional definitions and imagines space itself as a programmable/reconfigurable substrate.

Interesting transfer:
this is close to the later OBJECT → ADDRESS → OPERATION distinction, but it is materially grounded. It may be a better donor for HOUSE / ENV-0 / physical interfaces than abstract software metaphors.

### 6. GLYPH COMPRESSION ONLY EARNS ITS PLACE WHEN MOTIFS ARE TASK-MEANINGFUL

Source: Drive `Systematising Glyph Design for Visualization`.

The thesis treats glyphs as compact multivariate encodings but explicitly warns that replacing data with glyphs does not automatically make search easier. Motif selection must be meaningful to the task; glyph evaluation is a real design problem.

This sharply constrains current glyph ambitions:
- do not invent iconography because a surface looks dense;
- first identify recurring motifs that users actually discriminate;
- then test whether the glyph improves search/comparison/recall.

DataDisc's compound glyphs and TRIANGLE/AXIAL glyph work therefore need a task before a visual grammar.

## CURRENT / EXTERNAL PRECEDENTS

### 7. UN/FOLDING IS A USEFUL FORMALIZATION OF OUR DISCLOSURE PROBLEM

Bludau et al., *Fluidly Revealing Information: A Survey of Un/foldable Data Visualizations* (2025).

The survey studies 101 techniques and describes useful un/folding as:
1. reveal/reduce information on demand,
2. integrate into the base visualization,
3. preserve overall context,
4. maintain fluid interaction.

This is unusually close to the desired APERTURE / FOLD//BLOOM / Poem Map calm-face behavior.

Possible design test:
**does a reveal preserve object identity and spatial/contextual orientation, or does it feel like opening another app?**

### 8. TINDERBOX: ALIASES + AGENTS ARE A STRONG NON-DESTRUCTIVE MODEL

Current Tinderbox remains actively developed (11.8 in 2026).

Two mechanisms are especially relevant:
- aliases allow one note to appear in multiple places while remaining one underlying object;
- agents continuously collect matching notes as aliases instead of moving/deleting the originals.

This is a mature precedent for:
projection ≠ relocation,
membership ≠ identity,
automatic classification ≠ authority.

Potential transfer:
FIELD/Lens/Confluence could prefer generated *views/aliases* over moving canonical objects between categories.

### 9. KINOPIO IS A USEFUL APPROACHABILITY CONTROL

Current Kinopio's first interaction is essentially:
tap anywhere → type a card → drag a connection.

Boxes, lists, tags and bulk paint-selection deepen later.

The relevant lesson is not feature copying. It is that a spatial system can remain approachable when creation precedes ontology. Compare this against Poem Map 0.2's earlier cockpit problem.

### 10. EAGLE MODE IS AN INTERESTING ANTI-DONOR

Eagle Mode remains maintained in 2026 and commits fully to the ZUI idea: almost everything is visited by zooming through a virtual cosmos.

It is useful precisely because our likely answer is different:
semantic zoom is valuable as one projection, but **making zoom the universal navigation law can make every task inherit spatial depth whether it benefits or not**.

Keep as a comparison control for SCALE LENS / APERTURE, not a target aesthetic.

### 11. POETRY MACHINES ARGUES FOR UNEQUAL MACHINES, NOT THE IDEAL UNIVERSAL WRITER

Booten & Gero (2021) asked 14 professional poets to design desired computational “Poetry Machines.” Desired functions varied widely, including auditory responses and destructive/random operations, and were often grounded in specific artistic traditions.

Transfer:
the right unit may be a cabinet of small, opinionated transforms around a stable source, not one maximally capable assistant.

This supports retaining Pathweaver / Market+Solver / Verse Atlas / Poem Map as unequal instruments even if they share state/handoff contracts.

### 12. CO-POETRYME'S MOST RELEVANT UI LAW WAS CONTEXTUAL MODULE APPEARANCE

The paper describes visual modules around a central editable draft that are only visible when their actions are available. Selecting a word or line reveals the relevant controls; generated candidates can be banked rather than inserted.

This is a direct external precedent for the new Poem Map calm face and focus-wheel direction.

### 13. POEMPALETTE'S REAL DONOR IS THE MANIPULABLE INTERMEDIATE REPRESENTATION

PoemPalette (CHI 2026) turns selected poetic symbols into an editable scene graph before image generation. Users manipulate the intermediary instead of prompting an opaque end-to-end transformation.

The paper also reports an important caution: making users manually construct too much graph structure can itself create cognitive load; tedious structural work should be scaffolded.

Transfer beyond poetry:
when crossing modalities, expose a manipulable **middle object** with traceable source links—but automate boilerplate structure and reserve human effort for meaningful choices.

### 14. MORSE TRAINING SUGGESTS SCAFFOLDS SHOULD CHANGE MODALITY OVER TIME

A 2026 observational study of a public Morse trainer analyzed 699,562 records from 34,641 anonymous users. Visual cues were associated with better early accuracy/progress, while auditory cue benefit increased later in the teaching sequence.

Do not generalize the exact effect beyond that setting, but the design pattern is provocative:
**the best representation for acquisition may differ from the best representation for fluent use.**

Transfer candidates:
- guided → reduced-scaffold → fluent modes;
- visible path/glyph first, audio/haptic temporal code later;
- RSVP/Morse/Watch learning surfaces should consider scaffold fading instead of permanent multimodal clutter.

## CROSS-DOMAIN HYPOTHESES — NOT YET CLAIMS

### A. THE SELECTED OBJECT COULD BE THE UNIVERSAL UI ANCHOR; OPERATIONS NEED NOT BE UNIVERSAL

A source token, task, route, room surface, person/contact fragment or evidence claim can all support:
- focus,
- inspect,
- compare,
- project,
- preserve,
- return.

But the operations available after focus should remain domain-specific.

This may be the useful midpoint between “separate app for everything” and “one ontology for everything.”

### B. ALIAS / PROJECTION MAY BE MORE IMPORTANT THAN CLASSIFICATION

Instead of deciding where an object belongs, create lawful temporary collections:
- “things relevant to this question,”
- “same form support,”
- “current HOUSE devices,”
- “terms near this selected word,”
- “evidence touching this claim.”

This reduces category wars and preserves lineage.

### C. LEARNING / AUTHORING / OPERATING MAY SHARE A SCAFFOLD-FADING PATTERN

Early:
show relations, cues, explanations, affordances.

Middle:
compress into glyph/ring/path.

Fluent:
retain only the control channel and RETURN evidence.

This is visible independently in Pathweaver apprenticeship, Morse cue transitions, RSVP, AXIAL focus, and Poem Map 0.1→0.2.1 disclosure work.

### D. “INTERMEDIATE REPRESENTATION” MAY BE THE BRIDGE BETWEEN ART AND ACTION

Examples:
- PoemPalette scene graph,
- Poem Map candidate bank/path,
- AXIAL state×transform gate,
- ENV-0 symbols/interfaces,
- Workfield Q×OP unit,
- MARKET+SOLVER bag/constraints.

These are not merely visualizations. They are manipulable objects between raw source and consequential output.

Possible question:
which intermediate representations make the human *more capable*, and which merely externalize complexity?

### E. RECURRENCE SHOULD EARN COMPRESSION

The HAX archaeology says recurrence can justify caching/materializing physical configurations. The glyph thesis says recurring motifs can justify visual compression.

Potential common law:
**do not compress a structure until recurrence demonstrates that a stable shorthand is worth learning.**

This could prevent premature glyph systems, form adapters and universal vocabularies.

## THINGS THAT CURRENTLY FEEL FERTILE

No commitment implied.

- **ALIASES / LIVE VIEWS** rather than moving/categorizing canonical objects.
- **TASK-EARNED GLYPHS** generated from recurrence, not designed in advance.
- **SCAFFOLD FADING** across visual → temporal/audio/haptic channels.
- **MANIPULABLE MIDDLE OBJECTS** between source and generated/action output.
- **FIELD NOW as corpus**: use current work language as actual material for naming, compression and path experiments.
- **ONE OBJECT / ONE QUESTION** as a hard first-contact UI law.
- **ADMISSIBILITY → SMALL SURVIVOR SET → HUMAN CHOICE** as a reusable decision pattern.
- **GAME = ARTIFACT-STATE UNDER CONSTRAINTS**, not reward veneer.
- **PLAIN CONTROL beside every exotic projection** as an epistemic and usability discipline.

## THINGS TO RESIST

- Universal radial/zoom navigation.
- A single semantic graph that claims to explain every domain.
- Glyphs before recurring motifs/tasks exist.
- Permanent multimodal scaffolds.
- Auto-moving canonical objects when an alias/view suffices.
- One “smart” creative assistant that erases unequal artistic machines.
- Cultural/form adapters presented as neutral universal structures.
- Treating similarity, support, attention or visual proximity as truth.
