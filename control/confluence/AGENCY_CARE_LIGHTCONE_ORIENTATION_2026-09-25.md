**Status:** WORKING LENS / RECOVERED ORIENTATION  
**Role:** cross-lineage constraint, not a new app, ontology, diagnosis engine, planner, or authority.

## WHY THIS EXISTS

The collaboration already contains strong local mechanisms—FIELD, INTERPHASE, BODY, CARE, HOUSE, Dayline, HUMAN PORT, Scale Lens, Sleeper—but the higher-order agency/care lens was not present in the current repository even though it existed in earlier recovered work.

That omission creates a specific failure mode: local instruments can keep improving while the collaboration forgets what scale of agency, care, adaptation, and consequence they were meant to serve.

This file restores the missing orientation without creating a new sovereign system.

## EXTERNAL THEORETICAL DONORS — USE AS LENSES, NOT DOGMA

### 1. Cognitive light cone / computational boundary of a Self

Levin (2019) proposes a functional boundary around events a system can measure, model, and try to affect. The size of this spatiotemporal goal boundary is a cognitive "light cone."

Source:
- Michael Levin, *The Computational Boundary of a "Self": Developmental Bioelectricity Drives Multicellularity and Scale-Free Cognition*, Frontiers in Psychology (2019), PMID 31920779.

### 2. TAME / multiscale competency architecture

TAME treats agency as continuous, empirically probed, and substrate-agnostic. Cells, tissues, organs, organisms, and collectives can exhibit competencies in different problem spaces. The useful engineering question is not "is this really an agent?" but "at what scale, in what problem space, with what interventions does an agency model improve prediction/control?"

Sources:
- Michael Levin, *Technological Approach to Mind Everywhere: An Experimentally-Grounded Framework for Understanding Diverse Bodies and Minds*, Frontiers in Systems Neuroscience 16 (2022), PMID 35401131.
- Chris Fields & Michael Levin, *Competency in Navigating Arbitrary Spaces as an Invariant for Analyzing Cognition in Diverse Embodiments*, Entropy 24(6):819 (2022), PMID 35741540.

### 3. Stress → Care → Intelligence

Doctor, Witkowski, Solomonova, Duane & Levin propose Care as concern/action around mismatches between current and preferred states, and distinguish the space of possible behavior from the scope of goals/concern an agent can hold.

Witkowski et al. later formulate a stress–care–intelligence loop across biological, technological, and hybrid systems.

Sources:
- Thomas Doctor et al., *Biology, Buddhism, and AI: Care as the Driver of Intelligence*, Entropy 24(5):710 (2022), PMCID PMC9140411.
- Olaf Witkowski et al., *Toward an ethics of autopoietic technology: Stress, care, and intelligence*, BioSystems 231:104964 (2023), PMID 37394111.

### 4. Self-improvising memory

Levin (2024) treats memory less as perfect archival fidelity and more as adaptive reinterpretation across changing substrates and changing selves. A useful project translation is that durable identity can survive transformation through **salient invariants + provenance + re-interpretability**, rather than requiring every historical detail to remain active.

Source:
- Michael Levin, *Self-Improvising Memory: A Perspective on Memories as Agential, Dynamically Reinterpreting Cognitive Glue*, Entropy 26(6):481 (2024), PMCID PMC11203334.

### 5. Multiscale biomedicine

Levin's 2024/2025 "Multiscale Wisdom of the Body" argues for complementing bottom-up molecular control with higher-level interventions that exploit the native competencies of living collectives rather than attempting to micromanage every low-level variable.

Source:
- Michael Levin, *The Multiscale Wisdom of the Body: Collective Intelligence as a Tractable Interface for Next-Generation Biomedicine*, BioEssays 47(3):e202400196, PMCID PMC11848127.

## FIELD TRANSLATION — NOT CLAIMED AS LEVIN'S FORMALISM

For any important current object, we may ask:

```
AGENT / SELF
→ PROBLEM SPACE
→ PREFERRED REGION / MISMATCH
→ OBSERVATION BOUNDARY
→ ACTION BOUNDARY
→ COMPETENCY
→ HORIZON
→ CARE SCOPE
→ WITNESS
→ RETURN
```

Three FIELD-specific dimensions prevent "bigger care = better system" from becoming a slogan:

- **SCOPE** — what states / beings / times are represented as consequential?
- **RESOLUTION** — how accurately can the system distinguish what is actually happening?
- **EFFICACY** — what can it lawfully and competently change?

A wider SCOPE without RESOLUTION creates indiscriminate alarm.  
A wider SCOPE without EFFICACY creates obligation debt.  
High EFFICACY without appropriate SCOPE creates locally successful harm.

Therefore:

**CARE SCOPE ≠ COMPETENCE ≠ AUTHORITY.**

## CURRENT LINEAGE MAP

### BODY / FIELD — /body/

Owns low-burden self-observation and bounded self-experiment evidence.

```
NOW → PULSE → TEST → RETURN
```

It may describe patterns and before/after differences. It does not diagnose causation, triage, or treatment.

### CARE / FIELD — /care/

Owns longitudinal health/care episodes, sourced course state, observation vs interpretation, measurements, evidence references, and compressed clinician/vet handoff.

```
OBSERVE → FOLLOW → BRIEF
```

CARE is the higher-resolution longitudinal case projection. It does not acquire diagnostic or treatment authority.

### BODY / FIT — /body/fit/

Owns fitted devices, source-distinct sensor observations, Health Connect import, loadout sessions, RETURN/PATINA, and NEXT CUT residue.

It is a sensor / interface / preparation projection, not a health score.

### HOUSE CARE — /house/#CARE

This is a **household/environmental continuity projection**, not the canonical medical/self-care CARE lineage.

```
OBSERVED → ACTION/WATCH → RECEIPT → RETURN
```

It may lend an explicit action to Dayline or a minimized draft to HUMAN PORT. It must not absorb personal health cases merely because both use the word care.

### TRAINING — NO NEW SOVEREIGN ROUTE YET

Training is provisionally best understood as a repeated perturbation/adaptation protocol over existing carriers:

```
CAPACITY / TARGET
→ DOSE / PRACTICE
→ IMMEDIATE RESPONSE
→ RECOVERY / DELAYED RESPONSE
→ RETURN
→ NEXT EXPOSURE
```

Possible carriers:
- BODY for felt/current state and bounded TEST;
- Dayline for timing;
- BODY / FIT for sensors/equipment/loadout;
- CARE only when a longitudinal care/medical case genuinely needs to own the episode;
- HUMAN PORT for explicit coach/clinician/partner sharing.

Do not create a TRAINING app until repeated use demonstrates a missing function that these carriers cannot express.

## CONVERGENCE PATH

Convergence is not "put all data into FIELD."

It is:

```
ONE REAL OBJECT / AGENT
→ choose the problem space and scale
→ preserve exact address/source
→ expose 1–3 lawful operations
→ exploit competent lower-scale mechanisms
→ observe consequence at the relevant scale
→ RETURN evidence
→ update the model / widen or narrow the light cone
```

### Scale movement is explicit

A body sensation may become a BODY event.  
Repeated or consequential change may become a CARE case.  
A timed action may project to Dayline.  
A spatial/environmental constraint may project to HOUSE.  
A relevant other person may require HUMAN PORT.  
A durable general mechanism may transfer into FIELD.

**Projection upward is earned by consequence. Projection downward is earned by actionable resolution.**

## ANTI-COLLAPSE LAWS

1. **COGNITIVE LIGHT CONE ≠ SENSORY RANGE.**
2. **CARE SCOPE ≠ COMPETENCE ≠ AUTHORITY.**
3. **STRESS / MISMATCH SIGNAL ≠ OBJECTIVE HARM.**
4. **OBSERVATION ≠ INTERPRETATION ≠ ACTION ≠ OUTCOME.**
5. **ACKNOWLEDGED ≠ RESOLVED.**
6. **A HIGHER-SCALE GOAL DOES NOT ERASE LOWER-SCALE AGENTS OR THEIR CONSTRAINTS.**
7. **AN OBSERVER-CHOSEN PROBLEM SPACE IS A USEFUL MODEL, NOT THE UNIQUE ONTOLOGY.**
8. **TOP-DOWN CONTROL SHOULD EXPLOIT NATIVE COMPETENCIES BEFORE MICROMANAGING LOWER LEVELS.**
9. **WIDER CARE WITHOUT RESOLUTION OR EFFICACY CREATES DEBT, NOT INTELLIGENCE.**
10. **TRAINING / SELF-EXPERIMENT ≠ MEDICAL DIAGNOSIS OR TREATMENT AUTHORITY.**
11. **PRIVATE HEALTH/CARE STATE STAYS PRIVATE; THE PUBLIC REPO STORES MECHANISMS AND BOUNDARIES, NOT PERSONAL CASE CONTENT.**
12. **EVERY SCALE CHANGE MUST RETAIN A RETURN PATH TO THE SOURCE SCALE.**

## RELATION TO EXISTING FIELD LAWS

This lens does not replace:

- OBJECT → ADDRESS → LENS / PROJECTION → OPERATION → CHANGED OBJECT → RETURN
- SOURCE → ADDRESS → STATE → TRANSFORM → PROJECTION → PROVE → RETURN
- INTERPHASE: SOURCE / FRAME / FOCUS / OPERATE / WITNESS / RETURN
- FIELD EVOLUTION: CASE A → bounded mechanism → unequal CASE B → generalize only surviving invariant
- UNIFIED INSTRUMENT: one held object, one visible focus, few reachable moves, visible consequence, exact RETURN

It explains **why scale and authority matter** when those mechanisms cross bodies, people, rooms, agents, and time.

## CANDIDATE CROSS-DOMAIN INSTRUMENT

A future Scale Lens / INTERPHASE projection may expose a compact "agency passport":

```
SPACE      what can change?
TARGET     what region/state is preferred?
SENSE      what can be distinguished?
ACT        what can be changed?
HORIZON    how far in space/time/relations?
CARE       whose/which states count?
PROOF      what would show competence?
RETURN     where does this claim go back?
```

Do **not** implement this as a new store or mandatory form yet.

Promotion gate: it must reduce a real ambiguity in at least two unequal domains—for example one BODY/training case and one HOUSE/agent case—before becoming a shared runtime projection.

## ORIENTATION STATEMENT

FIELD is not trying to centralize every competent process.

It is trying to keep competent processes **addressable, composable, corrigible, and able to return evidence across scales**.

The desired trajectory is not maximum control.

It is:

**greater scope of care + better resolution + proportionate efficacy + preserved local competence + exact RETURN.**
