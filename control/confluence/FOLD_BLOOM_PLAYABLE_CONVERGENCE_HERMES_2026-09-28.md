## 3. What has already been learned

### 3.1 Exact state vs compressed state

The Fold/Bloom six-release exact form has `4^6 = 4096` possible verb histories.

The binary relation quotient has `2^6 = 64` hex states.

Therefore each complete HEX state aliases:

```text
4096 / 64 = 64 exact six-verb histories
```

That is a uniform loss of:

```text
log2(64) = 6 bits
```

Native falsification already showed that neither recent HEX nor recent exact six-verb history is sufficient to replace LIVE's actual control state.

**Use HEX as a lens/history witness, not controller truth.**

### 3.2 Endpoint change vs temporal path

For a change involving `k` moving lines:

- intermediate Boolean vertices: `2^k`
- one-line edges: `k · 2^(k−1)`
- maximal one-line orders: `k!`
- endpoint moving-set discards order information of approximately `log2(k!)` bits

The current change-calculus makes this residue visible and can address one exact order/path.

**The point is not mysticism. The point is making discarded temporal structure inspectable.**

### 3.3 Model suggestion vs lawful host action

The safe reusable chain is:

```text
MODEL/J-LENS READ
  → explicit direction ref
  → support against already-lawful host candidates
  → PREVIEW
  → host-native commit only if separately authorized
  → WITNESS
  → RETURN
```

No token label should silently become an operation.

### 3.4 Continuous vs stepped traversal

FLOW / STEP / RELEASE→STEP are not three products.

They are different address-motion policies over the same source:

- **FLOW** — source clock advances address.
- **STEP** — person advances one explicit source grain.
- **RELEASE→STEP** — commit one LIVE consequence, then advance exactly one addressed grain.

This pattern is likely reusable outside audio/text, but only as a traversal policy; do not turn it into a universal state machine unless another host proves the same missing function.

## 5. The deeper convergence: one instrument, unequal apertures

```text
OBJECT
  center = identity / held thing

  current native state; never silently replaced by projection

APERTURE
  scale or reading: WORD / SENTENCE / SECTION, BEAT / PHRASE / SECTION,

  a small host-native operation set

  visible/sensory consequence + provenance

  what the current projection omitted or compressed
```

This can recurse. A whole project can be one held object. A single sentence can be another. The contract stays similar while host semantics remain unequal.
