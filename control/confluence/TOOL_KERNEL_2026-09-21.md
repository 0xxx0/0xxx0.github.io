## Compression

The strongest defensible compression of the collaboration is not “many systems”.

It is a repeated attempt to preserve **continuity under transformation**:

```
SOURCE / OBJECT
→ ADDRESS
→ FOCUS
→ OPERATOR
→ PROJECTION / ROUTE
→ CONSEQUENCE
→ RETURN
```

One thing may lawfully become a map, poem, game, lens, file packet, physical mark, message, room view or research question while retaining enough identity/provenance to recover what happened.

This is a reconstruction of the recurring mechanism, not a claim that every historical project consciously implemented one master architecture.

The same recovered Sleeper visual names four arcs:

- **KITE** — productive tension: tether to what matters; constraint creates usable lift;
- **SPIRAL** — integration and return: retained differences are woven back into the changed system.

A cautious technical translation is:

```
BOUND / NAME TERMS
→ EXPLORE / DIVERGE
→ TETHER / SELECT / TEST
→ INTEGRATE / RETURN
```

This is a **candidate process donor**, not a claim that later Double Diamond, Fold/Bloom, FIELD evolution or other convergence loops descend from Sleeper. It is useful because it distinguishes four conditions we repeatedly confuse:
constraint is not imprisonment; freedom is not orientation; selection requires tension; integration is not flattening.

Test it only where those distinctions improve a real transition.

## THE IMPORTANT SUNDER-CUTS

1. **OBJECT ≠ PROJECTION.**  
   FIELD route / source / physical object survives MAP, Lens, AXIAL, page, spiral, image region or room view.

2. **OPERATOR ≠ INTERFACE.**  
   CUT, TRACE, ANCHOR and REPROJECT may recur in many interfaces. The recurrence is the mechanism; the screen is a carrier.

3. **INGRESS ≠ ADMISSION ≠ ACTUATION.**  
   HUMAN PORT may carry an addressed object; FIELD INTAKE may review/admit; HOUSE or an external channel may change reality. No stage inherits authority from the previous stage.

4. **MYTH ≠ PROOF.**  
   Mythopoetic language may compress and make operators memorable. It cannot establish lineage, truth, usefulness or permission.

5. **ARCHIVE ≠ ACTIVE SURFACE.**  
   Old exact artifacts stay recoverable. Current work imports only a named missing capability.

## WHAT “THESE SYSTEMS” ARE NOW

Not one mega-system.

> How can we change the reading, state, location, representation or consequence of something without losing what it is, where it came from, what changed, who authorized the change, and how to return?

Different heads answer different parts:
- FIELD — orientation / re-entry;
- AXIAL — lawful constrained focus;

- Intake — reviewed durable admission;
- House — physical state / actuation / measurement;
- Verse — language/path transformation;
- Sleeper / Workfield — semantic field + evidence-bearing run;
- CONFLUENCE — mechanism traffic across unequal lineages.
