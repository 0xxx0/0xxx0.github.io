## Management rule

For every material change, answer only:

1. **Which family changed?**
2. **What became possible that was impossible before?**
3. **What exact evidence exists now?**
4. **What can leave attention because of that evidence?**
5. **What is the one next conversion?**

If the change cannot answer one of those, it is probably coordination churn.

## Fixed point

The six families are not six apps. They are six roles in one field:

```
HOLD the exact thing
→ know the PATH when movement matters
→ TRANSFORM only within proved authority
→ make the EXPERIENCE worth entering
→ let it touch the WORLD
→ RETURN evidence
→ RECOVER only what the next real move actually needs
```
