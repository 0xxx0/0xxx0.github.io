## The knot

The collaboration accumulated several related but non-equivalent poetry/path systems. Navigation later made the Chinese verse work look as if it had become "Foundry", while some general path/grid and English/Latin donors looked lost.

The current evidence supports a cleaner split:

### 1. JUEJU / CHINESE POETRY PRODUCT INTENT
User-facing goal: a useful, shareable Chinese Poetry Copilot / composition-study instrument.

Canonical unresolved user line:
`未始来时末已示`

Important correction:
`空` was explored as an appended hinge/extension; it is not part of the canonical seven-character opener.

This product intent was repeatedly broader than a grid demo: composition, study, multiple readings, pinyin/gloss support, source fidelity, temporal reading, useful projections, and eventually sourced prosody/rime support.

### 2. ANTHROPY COMPOSER → PATHWEAVER
Exact donor:
`/recovery/path-grid/anthropy-pathweaver/`

Pathweaver is the strongest composition-heavy ancestor now recovered.

Implemented:
- four editable seven-character lines
- canonical unresolved opener in line 1
- lines 2–4 remain genuinely open
- explicit optional 空 hinge
- 2·2·3 / 4·3 / continuous cuts
- line-relation notes
- source → matrix → traversal → reading
- path → glyph
- path → WebAudio score
- source/provenance/session preservation

It is a donor, not the current public head.

### 3. GRID PATH COMPILER / FOUNDRY
Exact donor family:
`/recovery/path-grid/`

Foundry separated because the recovered ANTHROPY / grid work proved broader than Jueju.

Portable kernel:
`CELL → EDGE/BY → PATH → ADDRESS → VIEW → RETURN`

Corpus adapters remained unequal:
- Jueju / verse
- MEANTOME cell poetry
- Nine-Gate / ragged source field
- LATIN CONTROL
- custom matrices

This was a sound architectural separation:
**one path engine, not one poetry theory.**

Foundry is therefore a research/instrument substrate, not the Chinese Poetry Copilot product identity.

### 4. VERSE ATLAS
Current stable verse engine:
`/foundry/verse-atlas/`

Implemented:
- editable 4×7 Chinese verse
- stable line/character identities
- addressable grid projection
- typed path/BY transitions
- character-count verification
- explicit caesura projection
- pinyin + gloss study projection
- L3/L4 positional parallelism annotations
- route glyph
- RSVP temporal projection
- RETURN export/replay
- evidence firewall: historical rime and 平/仄 remain OPEN without sourced validators

Important limitation:
the current four-line default is a fixture. The earlier unresolved opener is shown separately and intentionally remains unmerged.

Verse Atlas is the strongest current Chinese-verse engine, but it is not by itself the recovered full "Chinese Poetry Copilot" product shell.

### 5. MEANTOME / CELL POETRY
Recovered exact donor:
`/recovery/path-grid/cell-foundry-r2/`

This is addressed cell poetry / graph traversal, not regulated verse.

Its authored route/seam/evidence mechanics are useful donors. It should not be relabeled Jueju.

### 6. LATIN / ENGLISH CONTROL
Recovered inside Grid Path Compiler V4.

It is explicitly:
**a boring geometry control with no literary or semantic claims.**

Therefore:
**English Jue Ju was NOT implemented.**

Do not rewrite history by calling LATIN CONTROL, Pathweaver's English source material, or the ANTHROPY English-poetry draft an implemented English Jue Ju.

If an English analogue is built later, it must declare its own poetic constraints instead of inheriting Chinese regulated-verse semantics by analogy.

### 7. JUE/JU FIELD-LAB GAME
Separate mini-game lineage.

Recovered conversation evidence describes a semantic-reordering game with glyph-laws and provenance, developed alongside RSVP and Kite.

This is not the same object as the Jueju composition/copilot lineage despite the name similarity.

Keep:
- JUE/JU = semantic/reordering game lineage
- Jueju / 絕句 = Chinese verse/composition lineage

until exact code/source proves a stronger relation.

## Why the split felt wrong

The **architectural split** was mostly correct:
- Foundry needed to carry multiple unequal engines/corpora.
- Verse-specific claims needed stricter evidence than generic path geometry.
- MEANTOME and Latin control should not be swallowed by Chinese poetry.

The **navigation/product split** was wrong:
- the user-facing Chinese Poetry Copilot ceased to be a clear top-level destination;
- Verse Atlas lived under Foundry, making the product feel like a subsystem of the lab;
- Pathweaver composition strengths remained frozen as a donor;
- "English/Latin" became easy to misremember as English Jue Ju;
- the JUE/JU game name contaminated the Jueju lineage.
