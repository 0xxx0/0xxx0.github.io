## Dependency laws

1. **RECOVERY → HOLD**  
   Recovery establishes *what the thing is* and where it came from. It does not decide what should happen next.

2. **HOLD → ALL**  
   Stable identity, address, focus and RETURN are shared substrate. Projection never gains native authority.

3. **PATH ⟂ TRANSFORM**  
   Path answers *how state was traversed*. Transform answers *what state changes/candidates are lawful*. They may compose, but neither substitutes for the other.

4. **PATH + TRANSFORM → EXPERIENCE**  
   Experience may borrow addressed traversal and lawful transforms while preserving source/effect ownership.

5. **EXPERIENCE → WORLD LOOP only through an explicit boundary**  
   A compelling interface is not permission to send, buy, actuate, schedule or mutate another host.

6. **WORLD LOOP → RETURN → native host**  
   Receipts/evidence go home. A world result may update native state only at that owner's explicit acceptance boundary.

7. **RETURN → REPLAN**  
   No successful move authorizes its sequel.

