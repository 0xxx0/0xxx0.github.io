# CONFLUENCE

Confluence is a coordination shelf for unequal lineages. It is not a universal ontology and it is not another current-head product.

## Working law

**Coordinate through explicit preserved relations, source links, differences, and return paths. Do not collapse vocabularies merely because two projects rhyme.**

## Thread / worker model

Treat chat threads and external agents as **context-local workers**.

They may have different working context, temporary hypotheses, and tool access. They are not assumed to share live scratch state.

Durable shared coordination lives in:

- `/control/CURRENT.json` — cold-start orientation / current heads / recovery targets
- `/showcase-manifest.json` — FIELD INDEX tracked public surfaces and touch metadata
- `/control/MIGRATION.json` — recover/import/quarantine work
- `/control/CENSUS.json` — artifact census
- `/returns/` — evidence / receipts
- this confluence shelf — bounded cross-lineage handoffs that should remain readable

The existing FI law remains authoritative:

> DISCUSSION ≠ INDEX TOUCH; MUTATION → INDEX TOUCH.

A thread can think for hours without changing shared durable state. If it commits a tracked surface, it must perform the corresponding FI touch.

## Agent roles

- **Hermes** — default read-only recovery / research / ambient operator unless explicit write authority is granted.
- **ChatGPT** — cross-thread retrieval, synthesis, steering, and context packets.
- **Codex / repo writer** — bounded implementation after a target and write scope are explicit.
- **Repository** — durable executable/public state.
- **RETURN** — evidence / ground truth.

This means a broad research charter may be handed to Hermes safely only when the role header below remains in force:

```
MODE = READ_ONLY_RESEARCH
NO repo writes
NO file moves/deletes
NO external actions
NO autonomous messaging
Implementation clauses become candidate patches/specifications only.
Return a bounded handoff packet with sources, deltas, uncertainties, and next executable actions.
```
