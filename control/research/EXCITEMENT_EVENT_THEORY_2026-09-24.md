# EXCITEMENT / CURIOSITY EVENT LAW — 2026-09-24

Status: **RECONSTRUCTED + PROVISIONAL RESEARCH ANCHOR**

This is not a reward system, psychological diagnosis, or universal game formula. It recovers a design question that emerged from FOLD//BLOOM, Poem Map, puzzle/path work and older Anthropy material:

> What makes a transformation feel worth anticipating, noticing, choosing and remembering?

## Recovered observations

Direct design signals from the current collaboration include:

- FOLD//BLOOM: **massive drops**, tunnel -> open sky, buildup -> plunge/release, pattern/section change, lyrics/text and embodied consequence were repeatedly associated with delight/immersion.
- The useful spectacle rule became: **rare + legible + consequential**, with all sensory witnesses sharing one addressed cause.
- Poem Map / puzzle-model work reframed authorship as a constrained search: state -> legal moves -> hard filter -> small survivor set -> human choice -> changed state -> RETURN.
- Older Anthropy notes connect sparse structure, crossword/game solvability, apophenia/agency, compression and surprise.
- Instrument charters already distinguish PASSION from PURPOSE/POWER/PROOF: lived value matters, but it must pay rent.

## Research support

Current curiosity literature supports several pieces without proving this exact design model:

- Novelty and uncertainty can have intrinsic information value and motivate exploration.
- A 2025 integrative appraisal model predicts curiosity from a knowledge gap that is relevant/novel **and** feels tractable enough to approach; low coping potential can push the same gap toward anxiety/avoidance.
- Information prediction error can enhance learning; absolute information value alone is not the whole signal.
- Explanation-seeking is predicted not only by novelty/surprise/information gaps but strongly by expected future learning and utility.
- Curiosity/exploration appears to balance novelty, uncertainty, information gain and learning progress rather than maximizing one permanently.

## Provisional event vector

Do not collapse this into one fake-precision score. Treat it as a gate/vector:

```
GAP          something remains unresolved / approaching
RELEVANCE    I care about what changes
COPE         I can understand or influence what happens
ANTICIPATION evidence arrives before resolution
CONTRAST     the event departs from its recent baseline
CONSEQUENCE  something actually changes afterward
COHERENCE    sound / image / motion / text witness one cause
RARITY       repetition has not flattened the event
RETURN       I can inspect what happened and continue
```

A candidate “exciting” event should normally satisfy:

```
RELEVANCE + COPE + ANTICIPATION + CONSEQUENCE
```

and earn amplification from:

```
CONTRAST + COHERENCE + RARITY
```

The **RETURN** condition prevents magic from becoming opaque spectacle.

## Failure modes

### Constant spectacle
If every beat is a drop, no event is a drop.

### Surprise without legibility
Unexpected motion with no causal witness reads as glitch/noise.

### Gap without coping
Mystery with no actionable foothold tends toward confusion rather than curiosity.

### Choice without consequence
Branches that reconverge invisibly are menu theater.

### Consequence without source identity
A beautiful transformation that cannot say what it transformed destroys trust/continuity.

### Explanation before encounter
Over-explaining the system can consume the curiosity the instrument was supposed to generate.

## Cheap experiments

### FOLD//BLOOM
Compare a real track with:
1. continuous high drama;
2. bounded macro events with anticipation and recovery.

Ask only: which events were noticed, anticipated, and remembered; which felt caused by the source; which user operation mattered.

### Poem Map
Present 2–7 legal survivor moves with visible constraint residue versus a free text suggestion list.

Measure:
- time to first intentional choice;
- reversals;
- chosen-path replay;
- whether the user can state *why this option was interesting* without reading system explanation.

### READFIELD / RSVP
Scaffold visible structure early, fade it at speed, preserve one rare orientation/return event rather than persistent ornament.

## Convergence consequence

The excitement law is not another app.

It is a **lived-value test** for projections:

```
SOURCE
-> ADDRESS
-> EXPECTATION / GAP
-> SMALL LAWFUL POSSIBILITY FIELD
-> HUMAN OR SOURCE EVENT
-> LEGIBLE CONSEQUENCE
-> RETURN
```

This connects FOLD//BLOOM, puzzle/poetry, reading, games and physical instruments without claiming their semantics are identical.

## Falsifier

Demote this model if boring baselines repeatedly produce equal or better agency/comprehension/delight, or if its variables cannot discriminate memorable useful events from decorative novelty.
