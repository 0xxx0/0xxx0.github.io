# SHAPE / LAW ATLAS 0.2

**Status:** R&D / working document  
**Updated:** 2026-09-25

## Why this exists

We keep encountering strong visual/process forms — triangle, radial field, path/grid, diamond, graph, ring, cylinder, simplex — and some of them contain real mathematics while others are only metaphors.

**Admission law:** name the invariant, constraint, objective or workflow first. Choose a shape/method only if its formal properties implement that thing. Reject post-hoc semantic mapping.

## The important distinction

**Three things ≠ triangle.**

- **Simplex / barycentric triangle:** three non-negative components constrained by a shared total.
- **Triangle-center geometry:** one triangle, many legitimate centers because each center answers a different criterion.
- **CIA triad:** three independent assurance objectives; no conservation law.
- **K₃,₃ utilities graph:** six vertices in a bipartite routing problem; its significance is non-planarity, not “three-ness.”
- **Graph coloring:** conflict assignment; unrelated to the utilities problem except both are graph theory.
- **Double Diamond:** divergence/convergence workflow; its diamonds are process notation, not metric geometry.

## Current method families

### GEOMETRIC
- Simplex / barycentric coordinates — valid for conserved three-way mixtures/allocations.
- Triangle centers / Euler line — valid when a center criterion has a real invariant.
- Voronoi / Delaunay — nearest-site territory and spatial adjacency.

### TOPOLOGICAL
- K₃,₃ / planarity — detects when a single crossing-free layer is impossible.
- Graph coloring — assigns incompatible adjacent objects to distinct channels/resources.

### MULTIOBJECTIVE
- Pareto frontier — preserves non-dominated options when objectives vary independently. This is often a better fit for shopping/build choices than forcing weights into a simplex.

### PROCESS
- Design Council Double Diamond — Discover → Define → Develop → Deliver; donor for disciplined divergence/convergence, not a replacement for RETURN.

### SECURITY / PRIVACY
- CIA — Confidentiality / Integrity / Availability objectives.
- STRIDE — six threat categories tied to actual flows/trust boundaries.
- NIST Privacy Framework — privacy-risk management; privacy is not merely confidentiality.

## MEREOLOGY / MULTISCALE ADDRESSED FIELD

The current LISTEN / READFIELD / GLYPH / AXIAL family exposes a recurring problem that is better stated as **part-whole + focus/context + scale** than as “make it radial.”

### Central law

**The whole persists while the aperture changes which part/scale is foregrounded.**

A useful canonical address is therefore not “a point on a ring.” It is closer to:

```
SOURCE
+ SCALE
+ SPAN / POSITION
+ PART-WHOLE RELATION
+ CROSS-RELATIONS
+ FOCUS / SELECTION
+ RETURN
```

Mereology is relevant because beats/phrases/sections/tracks, graphemes/words/sentences/paragraphs/documents, rooms/zones/objects, and route/focus structures all contain genuine part-whole questions. But **mereology is not automatically a tree**: recurrence, cross-reference, provenance, dependency and shared membership may cross the containment hierarchy. Preserve those relations rather than forcing one folder-like decomposition.

### Projection law

A radial / luopan-like carrier is justified only when it implements named semantics. Current candidate allocation:

- **center / fixed gate** — current addressed focus or invariant witness;
- **concentric bands** — scale/depth bands when scale ordering is real;
- **annulus / circumference** — wrapped extent such as time, sequence or cyclic address;
- **radial marks** — events, boundaries, pins, authored marks or relation crossings;
- **rim** — available operators / authority witnesses where useful;
- **aperture** — foreground resolution, not ownership of the source;
- **residue** — channels the projection cannot lawfully express.

This makes the “luopan” useful as a **co-registered multiscale carrier**, not as a universal ontology or decorative mandala.

### Focus/context precedent

The interface-research lineage already distinguishes several mechanisms that FIELD should not blur together:

- **overview + detail** — separate whole and focus spatially;
- **zooming / semantic zoom** — move through scale over time;
- **focus + context / fisheye** — foreground local detail while retaining surrounding structure;
- **cue-based suppression/highlight** — keep geometry stable while changing salience.

The current FIELD hypothesis is usually **co-present context + movable aperture**, with scale bands remaining available even when only one scale is active. That is closer to focus+context plus cueing than to “show every datum equally at once.”

### Current applied evidence

- **LISTEN** already uses BEAT → PHRASE → SECTION → TRACK as addressed temporal scales over one exact source, with pins/marks and source time retained.
- **READFIELD 0.8.3** keeps one source cursor through DOCUMENT → SECTION → PARAGRAPH → SENTENCE → PHRASE → WORD → GRAPHEME and now carries bounded focus into LOCI rather than restarting from source text.
- **INTERPHASE GLYPH** already separates identity core, depth rings, time/address annulus, operation/authority rim and explicit residue.
- **FIELD INDEX 0.8.2** makes Φ host/authority distinct from φ addressed focus, which prevents a focused projection from becoming the host.
- **SPIKE 005** strengthens the same distinction: rewind may restore an expression/focus frame without rewinding canonical host state.

These are correspondences, not proof that one visual carrier should replace the domain surfaces.

### Falsifiers / next tests

1. **LISTEN scale test:** on one real track, compare a single active ring against co-present beat/phrase/section/track witnesses. Keep simultaneous scale only if it improves orientation or re-entry without clutter.
2. **READFIELD scale test:** compare plain linear context with ring/focus context on a long source. If the radial carrier does not improve position/scale awareness, keep it optional or demote it.
3. **Cross-link test:** use an object whose relations are not a strict tree. If the carrier implies false parentage, the model fails until cross-relations are represented separately.
4. **Projection equality test:** the same source/focus address projected as LINE / RING / GLYPH must preserve identity and RETURN while allowing unequal residue. Similar appearance is not equivalence.

## Current bounded tests

1. **HOUSE / PLANARITY:** find one real single-layer routing/mark problem where K₃,₃/planarity changes the design.
2. **HOUSE / VORONOI:** test nearest-resource/adjacency on one tool/sensor/zone question.
3. **PROCUREMENT / PARETO:** prune dominated purchase/build options before applying preferences.
4. **HUMAN PORT / STRIDE:** threat-model one actual person/resource/agent flow and compare with current policy gates.
5. **DOUBLE DIAMOND / RECOVERY:** test whether explicit divergence/convergence improves one ambiguous recovery-to-build transition beyond our existing RECOVER → DISTINGUISH → ENACT → RETURN loop.

## Stop rule

Do not create a new canonical geometry family merely because one bounded test works. Promote only if a method repeatedly changes real decisions across at least two distinct heads while preserving source, constraints and RETURN.
