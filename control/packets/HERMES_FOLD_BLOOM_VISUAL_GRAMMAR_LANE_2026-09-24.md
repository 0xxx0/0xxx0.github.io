## PRIMARY QUESTION

Can 4–6 reusable visual event operators create a stronger, more legible experience than many continuous reactive effects?

## CANDIDATE EVENT OPERATORS

These are hypotheses, not requirements.

### COMPRESS
World narrows, information density collapses, peripheral motion converges.

### DROP
Horizon/body relation changes sharply; depth opens or falls.

### BLOOM
Occlusion releases; scale/space expands; color or geometry gains freedom.

### FOLD
Trajectory kinks, mirror/crease appears, path becomes locally non-Euclidean.

### SPLIT
One future becomes visibly two futures before user chooses.

### RETURN
Divergent geometry converges; visual residue resolves into source/address/orientation.

Potential extra:
### AFTERIMAGE
A prior event persists faintly as memory/provenance rather than particle decoration.

## HYPOTHESES

H1:
Distinct operators with stable visual laws improve event recognition and replay memory more than generic amplitude-reactive spectacle.

Falsifier:
Observers cannot distinguish operator classes after short exposure.

H2:
Anticipation should transform available **space/topology**, not merely increase zoom/vignette.

Falsifier:
Topology changes feel arbitrary or reduce orientation.

H3:
Afterimage/provenance can create continuity across events without persistent HUD.

Falsifier:
Residue reads as noise or visual clutter.

H4:
A bounded palette + contrast reserve makes rare events feel stronger than full-time high contrast.

Falsifier:
The base state becomes dead or event distinction remains weak.

## MEASURE

Machine:
- deterministic replay;
- frame budget on phone-sized viewport;
- no uncontrolled alpha accumulation;
- reduced-motion behavior.

Human/lived:
- can operator class be named/recognized?
- can event order be recalled?
- which event feels strongest and why?
- does the user anticipate a drop before it occurs?
- does RETURN feel like landing?
