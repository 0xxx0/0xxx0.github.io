## VISION

Investigate whether FOLD//BLOOM can become an **expressive replay instrument** rather than merely an impressive ride.

The important transformation is:

SOURCE
→ ADDRESSED MOMENT
→ EXPERIENCE / OPERATION TAPE
→ REPLAYABLE PERFORMANCE
→ MESSAGE / CLIP / LINK
→ OTHER HUMAN
→ RETURN

The user explicitly wants to use the instrument to communicate things.

## PRIMARY QUESTION

Can a short source-addressed performance become a communicative object that is:
- replayable;
- editable;
- compactly represented;
- visually compelling;
- understandable without explaining FOLD//BLOOM lore?

## HYPOTHESES TO TEST SEQUENTIALLY

Do not implement all at once.

### H1 — Operation tape before video
A share artifact is more powerful if its canonical representation is a tiny replayable state/operation packet and video/GIF is only one projection.

Falsifier:
If exact replay requires effectively recording every frame or too much hidden runtime state, the operation-tape claim is weak.

### H2 — Message mode is a projection, not a second editor
A user can bind a short authored line to one addressed source interval and choose a presentation law without creating a new timeline product.

Candidate presentation laws:
- EXACT
- MUSICAL
- CINEMATIC
- MESSAGE

Falsifier:
If useful authorship requires a full timeline/DAW-like editor, keep message work external or scoped differently.

### H3 — Replayability can come from expression, not scoring
Users may return to:
- refine a clip;
- compare two performance tapes;
- alter a branch;
- retime a phrase;
- generate a new visual rendering from the same tape;
without points/progression.

Falsifier:
If repeat encounters expose no meaningful skill or expressive delta, the current interaction has novelty but weak replayability.

### H4 — End-state orientation increases replay
A run that lands on a compact “where you were / what happened / replay/share/edit” RETURN may make the preceding ambiguity feel intentional rather than lost.

Falsifier:
If the RETURN is ignored or feels like admin chrome, orientation must move into the ride itself.
