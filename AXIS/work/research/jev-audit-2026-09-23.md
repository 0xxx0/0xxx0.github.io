## The contradiction (surface both sides)

| Source | Says |
|---|---|
| `hermes config get approvals.mode` | `smart` |
| `hermes config get auxiliary.approval.provider` | `typesafe-jev` |
| `ax/hermes-RnD-2026-09-22.md` §2.3 | "Jev approval gating — WIRED" |
| `plugins list` | `hermes-jev` enabled, `jev-approvals` enabled |
| **`jev/gate-events.jsonl` — 146/146 records** | **`mode: "off"`, `action: "disabled"`, `reason: "gate-mode-off"`** |

**Cause (COMPUTED):** the pre-tool gate is a *separate* mechanism from command approval, and its
setting is `plugins.entries.hermes-jev.settings.gate_mode`, whose default is `"off"`. Config
`plugins.entries` contains **only** `jev-approvals` — there is no entry for `hermes-jev`. So the
gate has never been on. Confirmed at the source: `hermes_jev/gate.py:200` —
`if gate_mode() == "off": ... action="disabled", reason="gate-mode-off"`.

**Which layer passed, precisely:** the decision/nervous/admission layer is *running and calling a
live provider*. The approval plugin is *configured and enabled*. The pre-tool gate is
*installed, logging, and off*. Yesterday's report verified configuration presence and treated it as
runtime behaviour — the same category error the `fix-verification` skill warns about.

Tools the gate would have observed (146 events): terminal 69, read_file 36, write_file 12,
web_search 5, search_files 4, web_extract 3, execute_code 3, kanban_show 2.

## The one bounded move (PROPOSED — not executed)

Gate modes are `off | advisory | enforce`. `advisory` observes and records without blocking —
reversible, no behaviour change to tool execution.

```
hermes config set plugins.entries.hermes-jev.settings.gate_mode advisory --force
```

Then verify at the layer that matters: run a few tool calls and confirm new `gate-events.jsonl`
rows carry `mode: "advisory"` rather than `"gate-mode-off"`. `enforce` only after advisory shows a
real disagreement signal worth acting on.

**Do not** go to `enforce` first. Advisory produces the evidence that tells you whether enforce is
worth its friction.
