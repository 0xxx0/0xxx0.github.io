# Forward Field // Proof

This branch is the stripped-down convergence experiment: one task substrate, two unequal projections, one local evidence stream.

## Use

- Choose a task and press **START**.
- **+ PATH** captures something missing. On first use, your first captured path replaces the demo paths.
- **+ ANCHOR** is only for a fixed commitment.
- **PAUSE** preserves a re-entry cue; **FINISH** calibrates duration terrain.
- **RETURN** opens the residue field; **STAMP RETURN** leaves a persistent red seal and a brief causal echo.

## PLAIN / FIELD ablation

Open **INSTRUMENTS → PLAIN / FIELD ABLATION** and press **BEGIN A/B**. The app assigns the underrepresented condition, freezes the representation, snapshots the current primary task / constraints / eligible opportunities, logs actions, and treats app hide/show as a natural interruption. Select another task and press **NOTICE** when you independently notice an opportunity. Press **END** and add the two subjective ratings.

The live summary is deliberately compact. **EXPORT EVIDENCE** downloads the raw local dataset.

`scoring.js` is the canonical pure scorer for exported evidence. It implements the stricter rules discussed in the research thread: wrong-first actions remain failures, clean latency excludes interruption time, recoveries are scored per interruption, constraint misses are action-level, and zero-opportunity trials are scored separately from opportunity recall.

No cloud account, no hidden AI priority inference, no global winner score.
