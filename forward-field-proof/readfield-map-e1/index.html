DONOR / ABLATION NOTE
The exact 2019 DataDisc donor uses 150 compound glyph discs on a two-revolution Archimedean spiral (r ∝ θ) with per-disc status channels. E1 intentionally removes all of that richness. The experimental DISC is one information-matched ring so the tested mutation is linear coordinate → stable angular coordinate, not “more channels versus fewer”.
DECISION LAW
TRANSFER: DISC median RT ≥15% faster and median positional error ≥20% lower.
HOLD / MODIFY: RT gain 5–15%, or strong error benefit offset by time cost.
NO TRANSFER: |RT gain| <5% and error gain <10%.
HARD REJECT: DISC >10% slower with no ≥15% error benefit.
Pilot result is not population-level proof.
