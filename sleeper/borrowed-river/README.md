# Borrowed River 0.1

Draw a route through an original ink landscape, sail around solid rocks under a finite ink budget, choose two branching landings, then follow your own river home. Download the changed painting or its replay-validated voyage.

## Recovered lineage

Recovered unfinished source: SLEEPER Site experiments/river, following Painting / Path and the request for inhabited, consequential painting play. The earlier reader/region study remains at /recovery/sleeper/painting-path/. Museum references supplied traversal and consequential objects; this landscape is AI-generated original artwork, not a historical painting. This is a bounded playable experiment, not an equivalent to a museum-scale game.

## Build and verify

Run `node build.mjs` and `node --test test.mjs` in this directory. Serve index.html over HTTP with landscape.jpg beside it. No dependencies or uploads. Source modules remain alongside the generated HTML.

Verified: independent path search completes all four upper/lower branch combinations, return-home closure, voyage and Return Artifact restore, impossible crossing rejection, forged completion rejection, altered destination rejection, unknown departure and enormous-coordinate rejection. Build completed. ## Contract and limits

`sleeper.borrowed-river` v1 stores actual crossing geometry. `sleeper.borrowed-river.return` v1 wraps the voyage plus derived words and distance. Both load through the same replay validator; derived metadata is recomputed rather than trusted. Keep original source IDs when writing future adapters. There is no automatic READFIELD, ONE RETURN, or music-map import yet.

The meaningful transfer candidate is an authored stroke that becomes both navigable space and a reversible route, ending in an inspectable artifact. Branches currently change collected words and the drawn route, not world physics. Human replay and enjoyment remain open evidence.
