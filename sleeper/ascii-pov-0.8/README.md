# ASCII Sleeper 0.8

Public experiment.

**Core:** source → unresolved contracts → coupled law field → traverse/resolve → RETURN → seal.

POV and PLAIN are unequal projections of the same gate state. The labyrinth therefore has a built-in cheaper baseline.

Four contracts:
- RECALL — mechanically checkable exact retrieval.
- OBSERVE — records a user observation; does not promote it to truth.
- DECIDE — records an explicit branch.
- ACT — records a bounded action/evidence attestation.

Each resolution changes its district and contributes through a coupling matrix to the global field. The Return seal compactly fingerprints source, evidence kinds, law branches, route and resulting field.

No backend, account, analytics or hidden inference.
