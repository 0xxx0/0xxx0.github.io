# HERMES SKILLS — CONFLUENCE/FIELD

Skills are executable methods, not slogans.

Admission rule:
- recurrence or repeated successful use;
- project-independent invariant;
- explicit trigger/input/output;
- known failure mode;
- verifiable procedure;
- bounded authority.

## Maturity

**CANDIDATE**
Procedure is explicit but still needs demonstrated use across contexts.

**PROVED**
Has survived at least one second-context application and its verification/failure boundaries remain useful.

**ACTIVE**
Operationally used as part of current workflows.

**PARKED**
Useful donor, not currently justified as an executable skill.

Do not inflate the catalog. If a method cannot reduce future rediscovery, keep it as research/confluence material instead.
