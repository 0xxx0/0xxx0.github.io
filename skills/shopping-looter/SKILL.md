# SHOP LOOTER

Purpose: refresh evidence for explicitly watched Shopping Field candidates without acquiring anything.

## Input

Consume a `shopping-looter-packet/v0.1` generated by Shopping Field or:

```
node scripts/shopping-looter-packet.mjs shopping-field-state.json
```

Only process packet.jobs. Do not invent adjacent shopping tasks.

## Authority

RESEARCH ONLY.

May:
- open/search public product and marketplace pages;
- verify exact variant/SKU/seller/condition when evidence permits;
- calculate landed SGD from visible components;
- record availability, return/warranty, pickup/logistics evidence;
- capture one trustworthy thumbnail URL tied to the exact listing/product;
- return UNKNOWN when evidence is insufficient.

May not:
- purchase or add to checkout as an action;
- message sellers;
- log in or change accounts;
- enter payment information;
- change Shopping lifecycle;
- infer ownership, receipt, fit, adoption, or seller identity from a teaser/snippet.

## Return

Return exactly `shopping-looter-return/v0.1`:

```json
{
  "schema": "shopping-looter-return/v0.1",
  "authority": "RESEARCH_ONLY / NO_EFFECT",
  "results": [
    {
      "item_id": "exact packet item_id",
      "source_state": "exact packet source_state",
      "checked_at": "ISO-8601",
      "source_url": "exact checked source URL",
      "exact_sku": null,
      "seller_channel": null,
      "availability": "UNKNOWN|IN_STOCK|LOW_STOCK|OUT_OF_STOCK|PREORDER|LOCAL_PICKUP_ONLY",
      "variant": null,
      "item_sgd": null,
      "local_freight_sgd": null,
      "gst_sgd": null,
      "landed_sgd": null,
      "return_policy": null,
      "warranty": null,
      "thumbnail_url": null,
      "notes": "short evidence / uncertainty"
    }
  ]
}
```

Every result must echo the item id and source lifecycle state. If the source listing changed identity, return UNKNOWN and explain it; do not silently substitute another item.

## Cadence / cron

Do one bounded manual proof first: at most 3 watched items, one return, explicit import into Shopping, inspect MARKET TAPE.

Only after that proof may a supervisor schedule repeated packets. The schedule is evidence refresh, never purchase authority. Prefer the item's own cadence_hours. A failed run yields a held/unknown return or no return; never fabricate freshness.

## RETURN

The human/app explicitly imports the result. Shopping revalidates exact id + lifecycle/source URL and appends evidence to MARKET TAPE. Native lifecycle stays unchanged.
