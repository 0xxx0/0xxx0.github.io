## Whole plan / ordinary life

For any one held object:

1. preserve its exact native source/address;
2. write only the **1–3 moves actually reachable now** on slot leaves;
3. fold the rest behind;
4. HOLD one while checking consequence and authority;
5. LET FLY once;
6. record what actually changed;
7. RETURN to the native owner;
8. only then expose the next neighborhood.

- HOUSE: selected place/context → one real spatial task.
