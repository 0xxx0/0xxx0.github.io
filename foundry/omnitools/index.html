TOOLS.

Each file is the whole tool. Self-contained instruments — one useful thing each, offline, copy-pasteable, no build step and no dependencies. Two run in the terminal; four run in the browser. Every one is tested against a real fixture before it is listed here.
OPERATIONS LAW: 1–3 reachable operations per tool · depth behind explicit reveal · values masked until asked for.
01 / EXPOSE

Find what identifies before the world does.

↗
CLI · NODE ≥18 · ZERO DEPS

PII-SCAN

Repo/PII pattern extractor: scans a git working tree and full history for emails, handles, secrets, keys, tokens, IPs, phones and probable names. Regex detectors + Shannon-entropy scoring, redaction mode, JSON output, fail-on severity for CI.

node pii-scan.mjs ~/repo --history --redact
 ↗
BROWSER · OFFLINE

PII LENS

The same detector family for pasted or dropped text. Scan a snippet, a log, a diff or a file without leaving the page. Values stay masked until REVEAL; findings export as JSON.

./pii-lens.html
02 / READ

Text becomes measurable, then re-readable.

↗
BROWSER · OFFLINE

TEXT LENS

Compact text-analysis suite: structure, lengths, Shannon entropy, Flesch band, script mix (Latin/CJK/Tamil/…), word and bigram ranks, lexical diversity. Re-measures as you type.

./text-lens.html
 ↗
BROWSER · OFFLINE

RE-READER

Tamil / Chinese / English re-reading overlay. Parallel blocks align by segment; VEIL hides the languages you are not reading yet and one click reveals exactly one row. Misalignment is shown, never hidden.

./re-reader.html
03 / MOVE

Data and scraped pages change shape without losing bytes.

↗
BROWSER · OFFLINE

RESHAPE

Data export desk: JSON / NDJSON / CSV / TSV in, JSON / CSV / NDJSON out. Quotes and embedded newlines honored; nested objects flatten to dot-paths so nothing is silently dropped.

./reshaper.html
 ↗
CLI · NODE ≥18 · ZERO DEPS

HTML-MUNGE

Scraped HTML to plain data: text, markdown, NDJSON link lists, table rows, or page meta. Reads a file, a URL or stdin. Script/style noise stripped before anything is measured.

node html-munge.mjs page.html --mode tables
