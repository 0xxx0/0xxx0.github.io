# LAW ZOO // FIVE MACHINES

Five standalone browser artifacts built from the tiny-law / high-phenotypic-leverage thread.

1. `law_zoo_field_guide.html` — the previously shipped specimen catalog.
2. `palimpsest.html` — self-render / sample / alphabet / rerender loop.
3. `law_districts.html` — first-person ASCII traversal through four local update laws.
4. `one_law_two_senses.html` — one recurrence state simultaneously drives canvas + WebAudio.
5. `error_garden.html` — heritable numerical faults in a deliberately restricted machine.
6. `index.html` — suite launcher.

No external libraries or assets are required.

Notes:
- WebAudio requires a user gesture before playback.
- LAW DISTRICTS uses keyboard and touch controls.
- PALIMPSEST can export PNG snapshots.
- ERROR GARDEN can breed two selected fault-genomes and export/copy a genome.
