# LAW ZOO // FIELD NOTES — 2026-09-13

## What was mined

The useful seam is not “best demos”; it is tiny **law families** with high phenotypic leverage under small syntactic mutation.

Primary veins:
- Dwitter: all-time/remix culture plus `#Automaton`, `#Attractor`, `#fractal`, `#Text/#ascii`.
- Tiny Code Christmas: canonical compact effect vocabulary (per-pixel fields, plasma, polar tunnels, scrollers, shadebobs, metaballs, connected dots, roto/perspective, voxel forms).
- MicroW8: machine constraints intentionally shaped for sizecoding; 320×240, 256 colors, 60Hz, tiny memory/API surface.
- KilledByAPixel/TinyCode: unusually valuable because it pairs tiny outputs with dissections of dweets and compact game/audio systems.
- JS1k: the bridge from “effect” to complete tiny world/instrument/game.
- Tweetcarts: fantasy-console micro-art as a living gallery.

## Distilled selection rule

Keep a law if:
1. a small parameter/operator mutation causes a large behavioral change;
2. it can generate more than one surface form (visual / sonic / spatial / game mechanic);
3. its failure mode is itself productive;
4. the underlying primitive is cheap enough to understand directly.

Drop an effect if it is beautiful but only reproducible as a fixed recipe.

## Strong reconnections to our existing work

These are lenses, not a new unified ontology.

### Sleeper / ASCII city
Use **local law districts** rather than merely procedural decoration. Modulo grids, cellular rules, turn-and-flip walkers, polar traversal, integer terrain and cyclic automata can each define a neighborhood's physics. Crossing a street can literally change the update law.

### Glyph / seal / typography lineage
Highest-value operators: coordinate folding, XOR textiles, framebuffer feedback, self-sampling ASCII, spiro ratios, moiré. These are not “patterns”; each can be made into a reversible mutation space where a glyph exposes what operation produced it.

### Music / work-trance
Do not map music to visuals. Let one recurrence produce both. De Jong/Lorenz coefficients, bytebeat integer expressions, phase ratios and cellular state counts are compact shared control sources.

### Physical / maker / House work
The useful borrowing is methodological rather than literal geometry: discover what the substrate gives cheaply. Coordinate folds and recursive branches can suggest fold/linkage families; implicit fields can visualize soft territories; modulo/bitwise laws can become stencil/cut/routing grammars. Do not treat any of these as structural proof.

## Sideways lane worth protecting

**ERROR GARDEN**: explicitly cultivate aliasing, low precision, singularities, feedback drift and unstable recurrence. The objective is not robust computation but discovery of species that disappear when “fixed.”

**SEDIMENTED RULE**: touching an environment changes its local transition law rather than drawing into it. History persists as altered response. This is a stronger successor to SILT than simply adding more particles.
